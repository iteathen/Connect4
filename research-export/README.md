# Connect4 research export

This branch is a download-oriented aggregation of Connect4 research that otherwise lives across multiple research branches.

The repository root is inherited from the `main` commit recorded in `MANIFEST.md`. Branch-specific research is copied under `research-export/branches/<name>/` without merging implementation histories.

Each snapshot is pinned to an exact source commit. Where present, `docs/`, `research/`, and `reference/` are copied as exact Git trees. Key root research/status files are also retained under `root/`.

Use `research-export/MANIFEST.md` for provenance, included source heads, intentional exclusions, and the export layout.

To download from GitHub: switch to branch `research/export`, then use **Code -> Download ZIP**.
