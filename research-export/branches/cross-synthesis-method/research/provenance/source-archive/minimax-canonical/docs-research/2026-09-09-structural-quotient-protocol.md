## Mechanism actually tested
For each player compile empty-cell requirements of lines without opposing stones. Remove duplicates and supersets of same-player requirements. Requirements are a disjunction of positive conjunctions. Own moves satisfy a variable; opposing moves invalidate terms requiring that variable. Subsumption is preserved under these substitutions, including terminal stopping. The support union bounds all future color dependencies; root-occupied cells stay in the key as constant salt. Erase only future colors outside that support; retain occupancy/heights. The normal mask+current encoding remains injective in prefix heights and retained colors.

Cache validity is ROOT-COMPILER-SCOPED: invalidate before a different compiled root. No cross-root persistence or cross-worker compiler mixing is claimed. A whole unfilled column outside BOTH supports is a finite neutral-turn reservoir, not a pass or permission to delete tempo. Keep the first legal neutral column in the original order and omit equivalent alternatives; preserve player/move-count and distance score. This is canonical physical representative selection, not a new literal token-state implementation.

Both requirements empty is a root draw certificate, separated from nontrivial gains. Requirements remain cold root data; recursion uses only fixed-width masks in the original solver. No per-node map, allocation, scheduler, cleanup or requirement recomputation is introduced. Move ordering for retained actions and tactical semantics remain unchanged; removing equivalent alternatives can still change heuristic transposition trajectories.

## Fairness and falsifiers
- Independent cell-array exhaustive game oracle; exhaustive 4x3 connect-3 reachable nonterminal graph for quotient values, action values and requirement transitions; independent 7x6 late-game exhaustive values for generated kernel qualification.
- One worker, identical exact distance-sensitive score, same TT entries AND bytes (14 bytes/slot), same kernel/publication, cold TT for every trial.
- Six ablations: base; compileTax (compiler with unchanged search); key-only; neutral-only; full; rawFull (same changes but without requirement subsumption).
- Common immediate-win check charged before compilation. Parsing/geometry/arena allocation are outside all timed solves. Compiler costs and admission are inside total time; clear costs measured separately.
- Every actual kernel warmed twice on the same million-node no-op-certificate root, then both structural branches exercised before timing. Rotate mode order and reverse corpus order between repeats; preserve all repeats.
- Root structural facts determine no-op routing, not hindsight timing. Dense roots pay compiler overhead then run the original body.
- Full exact solves, 20M-node safety cap per trial; limited trials reported, never silently dropped. No empty-board timed solve.
- Compilation uses small cold arrays. Report geometry and scratch separately, not falsely as zero-allocation or zero-overhead.
- Include no-TT independent oracle node counts to distinguish action reduction from TT hash effects. Include tempo-negative witness: deleting a neutral action is unsound.
- Exact disagreement invalidates that experiment. Matching baseline values is agreement, not an independent oracle for every large case. Shared publication is inherited and not concurrently qualified.
