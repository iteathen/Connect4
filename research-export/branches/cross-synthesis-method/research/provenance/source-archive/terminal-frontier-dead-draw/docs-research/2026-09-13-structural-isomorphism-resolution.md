# Structural isomorphism resolution

**Date:** 2026-09-13  
**Status:** active structural consolidation; no solver semantics changed  
**Branch:** `research/frontier-negamax-conformance`  
**Research direction / request to identify and resolve isomorphic structures:** **Josh Oshiro**  
**Formalization / synthesis / qualification:** OpenAI ChatGPT

## Purpose

The current Connect4 research stack accumulated several mathematically overlapping descriptions: posets, antimatroids, event structures, residual antichains, hypergraphs, blockers, dangers, gain-cost-rest fragments, matching/capacity, compatible covers, disjunctive causality, AND/OR proof DAGs, fixed points, pomset logic, and automata quotients.

This note resolves them by distinguishing five relations:

```text
EXACT REPRESENTATION EQUIVALENCE
  same semantic object, different coordinates

ORDER DUAL / DERIVED TRANSFORM
  same information viewed through a reversible or monotone dual operation

SPECIALIZATION / PROJECTION
  a restricted view of a richer canonical object

IMPLEMENTATION / PROOF LANGUAGE
  syntax or normalization mechanism, not new semantics

ANALOGY / OPEN HYPOTHESIS
  useful research lead, not admitted into exact logic
```

The goal is to remove duplicate semantic owners while preserving every load-bearing distinction.

## 1. Canonical exact architecture after resolution

The exact structural core reduces to six semantic layers plus one observation layer:

```text
E  causal event substrate
   finite gravity event poset + legal support ideals

R  residual obligation structure
   WSL residual winning-requirement antichains / blocker duals

P  parity / temporal constraint structure
   CPC GF(2) ownership, response, precedence and deadline facts

C  typed policy/resource structure
   coverage + response resources + compatibility + guards + deadlines + progress effects

N  guarded dependency closure
   NDC finite monotone hypergraph implications and shared consequences

G  alternating strategic proof semantics
   PreE / PreA, AND/OR proof DAG, safety/progress, least fixed point, W/D/L bounds

Q  observation-preserving quotient/output layer
   exact forward q for ordinary value transitions; q+Pi0 when terminal provenance is observable
```

The Bayesian layer remains outside all seven. It may rank research questions but cannot add a premise to `E/R/P/C/N/G/Q`.

## 2. Resolution class E — gravity, support, posets, antimatroids and event traces

### Canonical object

Let `P_E` be the future-event poset. For standard 7x6, it is the disjoint union of seven vertical chains.

For each column `c`:

```text
(c,h_c) < (c,h_c+1) < ... < (c,5)
```

### Exact representation equivalences

The following describe the same gravity-accessibility object:

```text
legal support configuration
<-> order ideal of P_E
<-> seven-column height vector
<-> element of the distributive ideal lattice J(P_E)
```

Because `P_E` is a disjoint union of chains:

```text
J(P_E) ~= product of the seven column-prefix chains.
```

The feasible support family is also the **poset antimatroid** generated by these ideals: it is accessible and union-closed. Antimatroid language therefore adds no new semantic layer for ordinary gravity support.

### Trace/confluence view

A legal history reaching one support ideal is a parity-colored linearization of enabled events. Independent events in distinct columns generate commuting diamonds whenever:

- both orders are legal;
- player coloring is preserved;
- no earlier terminal event cuts off one history.

Thus:

```text
product-poset diamond
partial-order / trace commutation
local event confluence
```

are the same local phenomenon.

### Resolution

Use **future-event poset + support ideal** as canonical semantics.

Treat:

- `poset positional game` as the surrounding game class;
- `antimatroid` as a derived accessibility view;
- `trace/event concurrency` as a quotient of irrelevant linearization order;
- general event structures only when conflict or alternative enabling not already represented by `N` is actually required.

Do not create separate state owners for these views.

## 3. Resolution class R — WSL, Sperner hypergraphs, monotone DNF and blockers

### Canonical object

For one player at fixed support, let:

```text
R_p = inclusion-minimal residual winning requirements.
```

`R_p` is an antichain of finite future-event sets.

### Exact representation equivalence

The same object may be read as:

```text
WSL minimal requirement antichain
<-> Sperner hypergraph / clutter
<-> minimal terms of a monotone DNF
<-> minimal true sets of the corresponding monotone completion predicate.
```

The logical formula is:

```text
F_p = OR_{r in R_p} AND_{e in r} own_p(e).
```

A move is a Boolean restriction/cofactor on this formula followed by absorption/minimal-antichain normalization.

### Blocker duality

For the uncluttered finite hypergraph semantics, the minimal transversal/blocker operation is a derived dual transform:

```text
b(R_p) = minimal hitting sets of R_p.
```

For a clutter, generic blocker duality gives:

```text
b(b(R_p)) = R_p.
```

This does **not** mean every minimal hitting set is a strategically realizable Connect4 defense. CPC, support, resources and deadlines still gate realizability through `P/C/N`.

### Danger/fork resolution

A `danger` is not a new base hypergraph. It is a **typed urgent projection** of residual obligations after a candidate event, together with a response neighborhood and deadline.

A `fork` is not a new primitive either. It is a failure of the response/compatibility relation to admit a common feasible transversal for the activated danger family.

Therefore:

```text
danger/fork calculus = R obligations + C response feasibility + P/N timing/guards.
```

### Resolution

Keep WSL residual antichains as the canonical requirement representation. Treat blocker, danger and fork objects as derived views/certificates over `R`, not parallel state universes.

## 4. Cross-cutting exact isomorphism — antichain normal form

Several apparently different calculi share one generic finite-poset representation theorem:

```text
monotone / upward-closed family
  -> store inclusion-minimal boundary antichain

downward-closed family
  -> store inclusion-maximal boundary antichain.
```

Instances already present in the project:

```text
WSL residual requirements          -> minimal antichain
proof-plan obligation alternatives -> minimal antichain when implication order is exact
pivot demand sets                  -> minimal antichain
feasible preservation families     -> maximal antichain
```

The last case is order-dual to the first three.

### Important non-equivalence

The antichain **normalization law** is shared, but the semantic domains are not interchangeable.

In particular, the bounded `4665655*` control established:

```text
28 exact-q proof terms -> 28 minimal terms
0 duplicates
0 strict-superset absorptions.
```

So exact-q proof-term subset order is mathematically sound but not materially compressive at that seam.

### Resolution

Promote `finite-poset antichain boundary representation` as a generic proof/representation lemma. Do not merge WSL requirements, proof obligations and preservation contracts merely because all use antichains.

## 5. Resolution class P — CPC, Zugzwang parity and even-release compatibility

### Canonical object

CPC owns parity-sensitive future-event control.

At the base reservoir:

```text
N(t) = (W - 1)H - ply + r + 1
owner parity = (N(t)-1) mod 2.
```

With a fragment changing the relevant prior-event reservoir by `Delta`:

```text
N'(t) = N(t) + Delta.
```

### Exact isomorphism already established

The owner event-rank method and Allis's even-release Zugzwang compatibility condition are the same GF(2) invariant:

```text
owner preserved <=> Delta mod 2 = 0
```

subject to the same support/resource/order guards.

Fixed ownership and response/split relations naturally form affine GF(2) constraints such as:

```text
x_e = 0/1
x_e XOR x_f = 0/1.
```

### Resolution

Use CPC/GF(2) event constraints as the one parity semantic owner.

Historical named parity/Zugzwang rules compile to CPC constraints. They do not define separate parity logics.

## 6. Resolution class C — response pairs, Allis compatibility, gain-cost-rest, matching, dangers and compatible cover

### Canonical object

Use the existing typed policy-fragment/resource-contract descriptor:

```text
Fragment F:
  Solves / Coverage
  Prerequisites
  Resources / footprint
  Response relation
  Sharing policy
  Parity/CPC commitments
  Event order
  Guards
  Deadlines / horizon
  Progress consequence
```

Composition is governed by exact compatibility/preservation.

### Specializations and projections

#### Vertical follow-up / Baseinverse / named Allis rules

These are **fragment generators**. Their useful semantic output is ownership, blocker, response, resource and deadline contracts. Historical rule names need not survive in compiled certificates.

The project already falsified same-column vertical follow-up as a globally complete calculus; it remains one fragment family.

#### Gain-cost-rest

`gain / cost / rest` is a compact projection of the canonical fragment:

```text
gain  -> initiating/progress event
cost  -> forced opponent/response resource consumption
rest  -> prerequisites / required future events
```

The canonical descriptor is richer because it additionally preserves sharing, parity, deadlines, guards and consequence.

#### Matching / Hall / flow

These are exact special cases when obligations consume simple interchangeable/unit-capacity response resources.

Once responses have guards, timing, reuse, exclusivity or parity commitments, the richer typed contract system is required.

#### Danger intersection / forks

For an activated danger family `D_i`, the ordinary common-response test is a projection of `CompatibleCover` onto the immediate response neighborhood:

```text
intersection_i Response(D_i) != empty
```

is a sufficient simple common-response case.

Empty raw intersection is not universally equivalent to strategic loss when multi-step, disjunctive or reusable policies exist; the exact object is the typed compatible-cover feasibility relation.

#### SAT/CSP

A finite SAT/CSP encoding of all fragment coverage and compatibility clauses is an exact implementation of the same finite cover problem when the encoding preserves all semantic constraints. It is not a separate proof semantics.

#### Infinite paving / follow-up

A paving strategy is naturally a closed family of response fragments that preserves safety under all enabled opponent events. This is a strong representational alignment, but the full translation of every published paving construction is not yet internally proved.

The finite-boundary-defect hypothesis becomes:

```text
restrict event substrate E
-> previously closed fragment family loses a required event/resource/compatibility relation
-> closure defect.
```

This remains a research hypothesis until the restriction theorem is formalized.

### Resolution

Use **typed compatible policy/resource cover** as the one semantic owner.

Treat named rules, gain-cost-rest, matching/Hall, danger intersections, paving and SAT/CSP as generators, special cases, projections or implementations of that owner according to the guards above.

## 7. Resolution class N — NDC, dependency DAGs and disjunctive causality

### Canonical object

NDC is already a finite guarded monotone implication system.

Represent each exact inference as a directed hyperedge:

```text
{premise_1, ..., premise_k} --guards/resources/time--> consequence.
```

### Exact representation equivalence

A proof DAG is the shared-subproof unfolding of this directed implication hypergraph.

Multiple distinct prerequisite hyperedges ending at the same consequence are exactly **alternative/disjunctive enabling sets**:

```text
A & B -> C
D & E -> C.
```

Thus the project's `alternative convergence` requirement does not need a second consequence object or branch matrix. It is ordinary shared-consequent hypergraph structure.

### Bundle/general event structures

Bundle or general event-structure notation may be a useful external syntax for the same alternative enabling pattern, but NDC remains semantic owner unless those formalisms add a proved needed distinction not expressible by NDC guards/resources/time.

### Resolution

Use **guarded NDC implication hypergraph** as canonical dependency semantics.

Disjunctive causality is a structural pattern inside NDC, not a separate calculus.

## 8. Resolution class G — E/A, AND/OR circuits, fixed points, safety and progress

### Canonical strategic semantics

The P0 winning region is:

```text
W = mu X . [ I union PreE(X) union PreA(X) ].
```

At a P0 node:

```text
Win(s) = OR_m Win(child_m).
```

At a P1 node:

```text
Win(s) = AND_m Win(child_m).
```

### Exact representations

The following are different presentations of the same alternating predecessor semantics:

```text
E/A recursive grammar
AND/OR proof DAG
alternating monotone Boolean circuit
least-fixed-point unfolding of PreE/PreA.
```

`collapse -> transport -> re-expansion` is ordinary Boolean simplification at a universal conjunction:

```text
AND(True,...,True)       = True
AND(True,...,C,...,True) = C
AND(True,C1,C2,...)      = AND(C1,C2,...).
```

The geometric vertical-pair mechanism was one way to generate the unary case; it was not the logical transport operator itself.

### Safety / liveness

Compatible-cover safety and forced progress are complementary proof obligations:

```text
safety: opponent completion is invariantly excluded
progress: a well-founded rank forces own completion.
```

A progress rank is an induction/ranking witness for membership in the least fixed point; it is not a separate game semantics.

### W/D/L intervals

The six nonempty convex subsets of:

```text
-1 < 0 < +1
```

form the project's bound/information domain. Player reversal is the order dual:

```text
[l,u] -> [-u,-l]
```

and exchanges max/min predecessor operations.

### Linear / pomset logic and focusing

These remain candidate **proof languages / normalization mechanisms** only.

They may help represent:

- resource-sensitive conjunction;
- player/environment choice;
- causal `before`;
- quotienting irrelevant proof permutations.

Until an exact semantics-preserving translation is proved and materially useful, they must not become a parallel logic layer.

### Resolution

Use alternating fixed-point semantics as the one strategic owner. Treat E/A grammars, AND/OR DAGs and progress ranks as proof presentations/certificates of that semantics.

## 9. Resolution class Q — q, residual automata and provenance refinement

### Canonical boundary

The accepted ordinary forward value-transition quotient is:

```text
q = supportIndex + normalized P0 residuals + normalized P1 residuals.
```

This can be viewed as a deterministic residual transition system / automaton state.

### Important limit

Do **not** call `q` the minimal Myhill-Nerode quotient unless minimality under the selected observation equivalence is separately proved.

The exact established claim is transition/value sufficiency for its declared projection.

### Output refinement

When terminal winning-line identity is observable, `q` is too coarse. `q+Pi0` refines the state with exact live P0 line provenance.

Thus:

```text
value observation  -> q
richer labeled output observation -> q + Pi0.
```

This is analogous to refining an acceptance automaton into an output-sensitive transducer, but output provenance remains Connect4-owned semantics.

### Resolution

Keep quotient/observation semantics separate from the strategic proof algebra. A proof compression is not automatically a state quotient, and a value quotient is not automatically an output quotient.

## 11. Bayesian-mask consequence

Isomorphic or nested representations must not be counted as independent evidence.

The Bayesian mask should cluster hypotheses by canonical owner:

```text
E-cluster: poset / ideals / antimatroid / traces
R-cluster: WSL / clutter / monotone DNF / blockers
P-cluster: CPC / Zugzwang / even-release / XOR
C-cluster: response pairs / Allis compatibility / gain-cost-rest / dangers / matching / paving / cover CSP
N-cluster: dependency DAG / disjunctive enabling / alternative convergence
G-cluster: E/A / AND-OR / fixed point / safety-progress / focusing candidate
Q-cluster: q residual transition quotient / provenance refinement
```

Evidence supporting two names inside one cluster is correlated unless it proves a genuinely distinct theorem.

The mask should place uncertainty primarily on the **bridges**:

```text
R + P + C -> compact exact safety certificate?
C + N      -> reusable typed implication/composition?
N + G      -> complete positive progress proof without state explosion?
E trace quotient -> material proof compression before enumeration?
finite restriction of paving -> exact boundary-defect theorem?
```

Those bridges, not the already-resolved representation identities, are the actual open research questions.

## 12. Resolved next research seam

The previous broad question:

```text
Which imported logic structure is the missing calculus?
```

is replaced by the narrower exact question:

> Can `R/P/C/N` compile the unresolved hard children into a small typed causal policy certificate whose `G` consequence proves safety plus well-founded progress, while `E` removes only interleavings proved irrelevant?

For the fixed `4665655*` sibling controls, the cheapest discriminator is therefore not another ontology search and not deeper recursion.

Construct only the canonical typed object:

```text
residual obligations R
+ CPC/time facts P
+ compatible response/resource contracts C
+ NDC implication edges N
```

and ask whether the three closing siblings have a shared finite certificate pattern that the broad sibling lacks.

Danger intersections, gain-cost-rest fields, blocker duals, Hall deficiencies and Allis fragments may all be used as **derived projections** of this object to expose the difference, but no derived projection becomes a second semantic owner.

Every experiment remains under the five-minute wall-clock rule.
