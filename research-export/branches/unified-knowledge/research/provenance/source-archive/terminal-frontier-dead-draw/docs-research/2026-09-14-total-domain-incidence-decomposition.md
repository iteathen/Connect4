# Total-domain Connect-4 incidence decomposition

**Research direction / structural architecture / invariant-first and self-proving-predicate program:** Josh Oshiro  
**Formalization / implementation / qualification:** OpenAI ChatGPT

## Purpose

Derive the empty-board Connect-4 incidence/core objects for every positive integer rectangle `W x H` from one decomposition. Small boards are not handled by a separate mode, and no finite board sweep is evidence for the quantified formulas below.

The key correction is methodological: decompose the generated line system before taking ranks or searching for cross-board isomorphisms.

## 1. One-dimensional Connect-4 window space

Let

```text
E_n = F2^n
```

with coordinate basis `e_0,...,e_(n-1)`. For every legal length-4 start `s`, define

```text
u_s = e_s + e_(s+1) + e_(s+2) + e_(s+3).
```

Let `A_n` be the span of the generated `u_s`.

Write

```text
a_n = (n-3)_+
p_n = min(n,3).
```

The `u_s` are independent by their leftmost pivots, hence

```text
dim A_n = a_n,
dim(E_n/A_n) = n-a_n = p_n.
```

This is already total-domain. If `n<4`, no length-4 window exists and `A_n=0` automatically.

For `n>=4`, the quotient `Q_n=E_n/A_n` obeys

```text
[e_(j+3)] = [e_j]+[e_(j+1)]+[e_(j+2)]
[e_(j+4)] = [e_j].
```

The second identity follows from the first over `F2`. Equivalently, the Connect-4 window polynomial is

```text
1+x+x^2+x^3 = (1+x)^3  over F2,
```

so the quotient is the third finite-difference/derivative residue of the axis.

## 2. Horizontal/vertical tensor decomposition

For a `W x H` board let

```text
a=(W-3)_+
b=(H-3)_+
p=min(W,3)
q=min(H,3).
```

The cell space is

```text
C = E_W tensor E_H.
```

The horizontal and vertical winning-line spans are

```text
Hspan = A_W tensor E_H
Vspan = E_W tensor A_H.
```

Their intersection is

```text
Hspan intersect Vspan = A_W tensor A_H.
```

Therefore

```text
dim(Hspan+Vspan)
  = aH + Wb - ab
  = WH-pq.
```

Equivalently,

```text
C/(Hspan+Vspan) ~= Q_W tensor Q_H
```

with dimension `pq`. Thin boards therefore collapse because their axis residue spaces shrink; no board-size case is introduced.

## 3. Diagonal residue theorem

Diagonals can change the incidence rank only through `Q_W tensor Q_H`.

If `ab=0`, no length-4 diagonal exists and the diagonal residue rank is zero.

Assume `ab>0`. In either axis quotient write the four periodic residues as

```text
r0, r1, r2, r3=r0+r1+r2,
```

and similarly on the height axis.

A direct four-term quotient calculation gives two nonzero distinct tensors `P,Q` such that every rising diagonal residue is

```text
P when x+y is even,
Q when x+y is odd.
```

Parameterize a falling diagonal by its bottom-offset start `t`, so its cells are `(x+i,t+3-i)`. Its quotient residue is governed by the same checkerboard parity `x+t`: `P` on even starts and `Q` on odd starts.

Thus all generated diagonal residues span at most `{P,Q}`.

- If `ab=1`, necessarily `a=b=1`; there is one start in each orientation and both have the same residue. The diagonal residue rank is `1`.
- If `ab>=2`, the rectangular start set contains starts of both checkerboard parities because at least one side has length at least two. Hence both `P` and `Q` occur, and the diagonal residue rank is `2`.

Therefore for all positive `W,H`,

```text
d = min(2,ab)
```

is exactly the rank added by the diagonal direction classes beyond `Hspan+Vspan`.

## 4. Total-domain incidence rank and kernel

Let `B` be the GF(2) map from generated geometric winning lines to board cells. Then

```text
rank(B) = WH - pq + d
        = WH - min(W,3)min(H,3) + min(2,(W-3)_+(H-3)_+).
```

This is one formula for every positive board size.

The total generated line count is already proved as

```text
L = Ha + Wb + 2ab.
```

Using `W=a+p`, `H=b+q`,

```text
L = 4ab + aq + bp,
rank(B) = ab + aq + bp + d.
```

Hence

```text
dim ker(B) = L-rank(B) = 3ab-d.
```

Again no small-board branch appears.

Examples are consequences, not premises:

```text
1x1: rank(B)=0, ker=0
1x4: rank(B)=1, ker=0
2x4: rank(B)=2, ker=0
3x4: rank(B)=3, ker=0
4x4: rank(B)=8, ker=2
7x6: rank(B)=35, ker=34.
```

## 5. Axis quotient is another direct factor

Let the cell-axis map record row and column parity of a cell incidence vector.

- a horizontal length-4 line contributes its width interval `u_s` and zero row parity;
- a vertical line contributes its height interval and zero column parity;
- a diagonal contributes one interval in each axis and therefore adds nothing outside the spans already generated by horizontal and vertical lines.

Therefore, for all positive `W,H`,

```text
rank(Q_axis) = a+b.
```

The total-domain cell core is consequently

```text
Y_cell
  = rank(B)-rank(Q_axis)
  = WH-pq+d-a-b.
```

This specializes automatically to the old regular formula:

```text
W,H>=4 and not 4x4 diagonal-rank degeneration encoded by d:
Y_cell = WH-W-H-1
```

when `p=q=3` and `d=2`.

It also stays defined on every thin board without replacing the structural object:

```text
1x1 -> 0
1x4 -> 0
2x4 -> 1
3x4 -> 2
7x6 -> 28.
```

These are structural dimensions, not W/D/L labels.

## 6. Kernel decomposition before phase

The kernel itself has a useful exact decomposition.

The horizontal/vertical-only coefficient map has kernel

```text
K_HV ~= A_W tensor A_H
```

of dimension `ab`: each tensor `u_s tensor u_t` has one horizontal representation and one vertical representation whose sum has zero cell incidence.

Project a full line dependency onto its two diagonal coefficient families. The image must lie in the kernel of the diagonal residue map

```text
rho : D_plus direct-sum D_minus -> Q_W tensor Q_H.
```

The latter has dimension

```text
2ab-d.
```

There is therefore an exact sequence

```text
0 -> K_HV -> ker(B) -> ker(rho) -> 0,
```

whose dimensions give

```text
ab + (2ab-d) = 3ab-d.
```

This is the decomposition to use before studying the gravity-oriented phase map. A vector-space splitting exists but is not asserted natural; the exact sequence is the invariant statement.

## 7. Phase quotient decomposition

Let

```text
Vphase : ker(B) -> F2^W
```

record the parity of selected vertical winning-line coefficients in each column.

### 7.1 Horizontal/vertical coupling contribution

For the basis relation associated with `u_s tensor u_t`, the vertical representation selects one vertical line in each of the four columns of `u_s`. Therefore its phase vector is exactly `u_s`.

If `ab>0`, the `K_HV` sector contributes all of `A_W`, of dimension `a`. If `ab=0`, this sector is absent.

Its exact contribution is therefore

```text
r_HV = min(a,ab).
```

### 7.2 Diagonal phase residue

To see the remaining phase information modulo `A_W`, define a height functional `g` by

```text
g(e_y)=1 iff y = 3 mod 4.
```

Every four-consecutive-cell height interval contains exactly one such residue, so

```text
g(u_t)=1
```

for every generated vertical length-4 interval.

Apply `pi_W tensor g` to a zero cell-incidence dependency, where `pi_W:E_W->Q_W` is the width quotient. Horizontal contributions vanish modulo `A_W`; vertical contributions become the width residue of the vertical phase vector. Thus the phase residue is determined entirely by the diagonal coefficients.

For a rising diagonal start `(x,t)`, the unique selected height residue occurs at `i=3-t mod 4`, giving phase residue

```text
r_(x+3-t).
```

For the falling diagonal with cells `(x+i,t+3-i)`, it occurs at `i=t mod 4`, giving

```text
r_(x+t).
```

The two orientations at one start have the same `rho` residue, so selecting them together is always a valid diagonal-residue cancellation. At `(0,0)` this yields

```text
r3+r0 = r1+r2.
```

If `a>=2`, the same construction at `(1,0)` yields

```text
r0+r1,
```

independent of `r1+r2`; hence the diagonal phase residue has rank two.

If `a=1`, only `x=0` exists. For `b=1` or `b=2`, each available checkerboard residue class contains only its two orientation instances and both orientation-pair cancellations yield the same vector `r1+r2`; the residue rank is one. Once `b>=3`, starts `t=0` and `t=2` share a checkerboard class; selecting (for example) their falling instances yields `r0+r2`, independent of `r1+r2`, so the residue rank becomes two.

A compact total-domain expression for this diagonal phase-residue rank is

```text
r_D = min(2, ab, a + floor((b-1)_+/2)).
```

Therefore

```text
rank(Q_phase)
  = r_HV + r_D
  = min(a,ab) + min(2,ab,a+floor((b-1)_+/2)).
```

This single formula contains the old regular and narrow results:

```text
W,H>=5: W-1
4x4: 2
4x5: 2
4xH, H>=6: 3
W<4 or H<4: 0.
```

The old `4x4` and `4x5` phase exceptions are therefore not separate axioms. They are the shapes where the diagonal-start neighborhood is too small to realize both phase-residue generators.

## 8. Total-domain line core

Since

```text
dim ker(B)=3ab-d,
```

the gravity-oriented line core is

```text
Y_line
  = 3ab-d
    - min(a,ab)
    - min(2,ab,a+floor((b-1)_+/2)).
```

This is defined for every positive `W,H` using the same generated objects.

On standard `7x6`:

```text
a=4, b=3, p=q=3, d=2
rank(B)=35
ker(B)=34
rank(Q_axis)=7
rank(Q_phase)=6
Y_cell=28
Y_line=28.
```

Thus the standard common 28 is recovered as one point of the total-domain decomposition rather than as a constant or a regular-board special case.

## 9. Why this matters for invariant-isomorphism search

Do not canonicalize the raw board first. The decomposition identifies the load-bearing objects before any cross-board comparison:

```text
axis window spaces A_W,A_H
third-difference residues Q_W,Q_H
horizontal/vertical coupling A_W tensor A_H
diagonal checkerboard residue map rho
diagonal phase-residue map
cell core and line core.
```

A useful isomorphism must preserve these relations and their coupling maps. Equal scalar ranks are only consequences.

This also supplies a diagnostic when another system fails to reveal an invariant: first ask whether its primitive constraints factor into derivative/window spaces and small residue quotients, whether a required derived axiom is missing, or whether the chosen coordinates obscure the coupling shape.

## Proof boundary

The rank formulas above are symbolic consequences of the generated length-4 window spaces, tensor quotient, period-four recurrence, and diagonal start-parity geometry. Finite executable controls may be used only to catch implementation/algebra errors.

No solved W/D/L label, optimal move, terminal distance, board census, recursive minimax/Negamax/MCTS/PNS, or predefined `28` is used as a premise.
