## Result

The poisoned-support work proposed that the positive predecessor calculus might reduce to a small set of structural leaf predicates plus alternating existential/universal closure. This was tested exhaustively on the complete `4x3 connect-3` game.

The complete control contains:

```text
4,659 reachable nonterminal states
11,818 legal edges
2,627 P0-win states
327 draw states
1,705 P0-loss states
```

The inference pass did **not** use those W/D/L labels. It seeded only two P0-winning structural leaf classes:

```text
I = P0 to move with a playable singleton completion
O = P1 to move, no immediate P1 counterwin, and every legal P1 move releases a P0 playable singleton completion
```

Then it closed only under the game-theoretic predecessor operators:

```text
E(X): P0 has at least one child already proved in X
A(X): every legal P1 child is already proved in X
```

After saturation, the derived set contained exactly:

```text
2,627 states
```

Independent comparison with the complete exact W/D/L control produced:

```text
false positives      0
false-negative wins  0
```

Thus this closure reconstructs the entire P0-winning attractor on the complete small game.

## Root proof grammar

The empty root closes at structural proof rank `7`; maximum rank over the full winning region is `8`.

Using a minimum-rank witness for each existential node and quotienting identical dependency expressions, the selected root proof contains:

```text
38 physical states
9 unique structural proof shapes
```

The root shape is:

```text
E(A(E(A(E(A(E(O)|I))|I))|E(O)))
```

The nine unique shapes are exactly the same cardinality as the independently measured nine-node W/D/L root dependency DAG recorded by the earlier searchless-dependency experiment.

More strongly, the grammars are structurally isomorphic:

```text
terminal/immediate win         <-> I
losing-player response overload <-> O
winning witness predecessor     <-> E(...)
losing-player universal proof   <-> A(...)
```

The new result therefore supplies structural meaning for the previously observed proof-shape quotient rather than merely reproducing its size.

## Response-overload leaves

The selected empty-root proof contains five `O` leaves. Every one is discharged by the local response-capacity predicates already derived in the poisoned-support calculus:

```text
two distinct playable singleton completions
and/or
stacked singletons: playable lower completion + latent upper completion released by the lower response
```

No additional tactical leaf class was needed for the root proof.

This is important: the local positive base cases are now accounted for by

```text
WSL singleton requirements
+ support/playability
+ first-win timing
+ response-capacity overload.
```

## What remains missing

This experiment deliberately used the complete physical state graph as a control substrate, so it is **not** a searchless production solve.

However, it moves the missing-calculus boundary substantially.

The gap is no longer:

```text
what does a winning proof look like?
```

For the complete 4x3 root, the proof grammar is now generated by only:

```text
I, O, E, A.
```

The remaining gap is:

> derive the `E/A` proof-obligation DAG directly from CPC + WSL + support/event + NDC facts without materializing the physical child-state graph.

Equivalently, the unresolved calculus is **alternative-class generation and convergence**, not terminal semantics.

A production structural rule should prove statements such as:

```text
there exists a P0 alternative in proof class C
```

or

```text
all P1 alternatives fall into already-proved classes C1..Cn
```

from relations among residual requirements, support order, parity, response capacity and deadlines, rather than by visiting each physical successor.

## Connection to the 7x6 center defect

This result strengthens the center-opening program.

The 7x6 safety analysis exposed one bottom-row cover defect. The response-capacity calculus and poisoned-support theorem show how a defender repair can become a progress resource for the attacker. The complete 4x3 control now proves that exactly this kind of overload can serve as the terminal base of an entire winning proof grammar.

Therefore the next 7x6 question should be phrased as an `E/A` generation problem:

```text
Can every defender repair/avoidance alternative around the center defect be mapped, through CPC/WSL/NDC, into a finite set of stronger proof classes that converge to response overload?
```

If yes, the positive center proof can be represented as a small structural dependency DAG rather than a move tree.
