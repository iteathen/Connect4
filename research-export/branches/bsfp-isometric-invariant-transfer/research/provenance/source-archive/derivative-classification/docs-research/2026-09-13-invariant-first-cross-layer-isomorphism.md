## Purpose

The previous pass resolved surface-level formalisms into canonical semantic owners:

```text
E causal event substrate
R residual obligations
P parity / temporal constraints
C typed policy / resources
N guarded dependency closure
G alternating strategic proof
Q observation quotient / provenance
```

This pass goes one level deeper. Instead of comparing names or whole calculi, identify the quantities and relations that remain invariant under each layer's legitimate representation changes, then compare those invariants across layers.

The goal is to expose isomorphisms that are hidden because the same structure appears once as geometry, once as parity, once as resources, and once as proof.

The Bayesian mask remains external. It may rank which candidate bridge to test but contributes no premise to exact logic.

## 2. Hidden exact isomorphism A — one master rank drives E, P and G

Let:

```text
rho(I) = |I|
```

be the rank of the support ideal.

The same integer appears in three apparently different roles.

### E: causal grading

Every legal move increases:

```text
rho -> rho + 1.
```

Thus `rho` grades the support lattice.

### P: parity quotient

Global side-to-move is determined by:

```text
rho mod 2.
```

The base CPC target equation is an affine mod-2 function of the same event rank plus target-dependent constants. Even-release invariance is precisely membership in the kernel of the reduction:

```text
Delta -> Delta mod 2.
```

### G: progress grading

The natural remaining-event rank is:

```text
mu = 42 - rho
```

and every physical move decreases `mu` by one; every retained two-ply macro-step decreases it by two.

### Resolution

There are not three unrelated notions of rank.

```text
master event rank rho
  -> causal grade           E
  -> mod-2 character        P
  -> reversed well-founded rank G
```

This is exact.

Consequences:

1. parity claims and progress claims should state which projection of `rho` they use;
2. deadline/horizon facts can often be represented as rank inequalities;
3. a candidate abstraction that erases `rho` must independently preserve both its mod-2 image and its well-founded-order image.

## 3. Hidden structural equivalence B — N and G are the same fixed-point skeleton on different domains

NDC closure has the form:

```text
X* = mu X . [ X0 union Consequences(X) ].
```

The P0 winning region has the form:

```text
W = mu X . [ I union PreE(X) union PreA(X) ].
```

Both are monotone operators over finite ordered domains and are solved by least fixed-point induction.

Safety invariants similarly admit greatest-fixed-point form.

### What is exact

The **fixed-point skeleton** is the same:

```text
finite ordered domain
monotone transformer
least/greatest fixed point
ranked induction / convergence witness
```

### What is not the same

The semantic domains differ:

```text
N: facts / certificates / implications
G: strategic state sets / value bounds
```

Therefore N and G should not be merged semantically, but they need not have independent fixed-point machinery.

### New bridge interpretation

The old question:

```text
N -> G ?
```

can be sharpened to:

> Which N-closure consequences are sufficient to make the G transformer collapse without expanding exact-q children?

A still stronger candidate is a monotone product-domain operator over:

```text
N-facts x G-bounds
```

provided every feedback edge is proved monotone and preserves horizons/resources.

This is a candidate implementation/proof organization, not yet a promoted solver contract.

External closure-system/Horn literature supports treating a finite monotone implication system by its closure operator rather than by one accidental rule basis. Canonical/direct implicational bases are therefore relevant to minimizing N without changing `Cl_N`.

## 4. Hidden self-isomorphism C — R and one-step G proof terms are the same monotone-Boolean shape

At fixed support, R represents:

```text
F_R = OR_{r in R_p} AND_{e in r} own_p(e).
```

At a P0 strategic decision after one macro-step, pure positive proof has form:

```text
F_G = OR_{action a} AND_{q in H(a)} Win(q).
```

So both are monotone DNF.

The previously tested exact-ID absorption rule was only the identity-order specialization:

```text
H(a1) subset H(a2)
=> term a2 is redundant.
```

The bounded sibling control showed that this specialization gives zero material compression.

### Hidden stronger normalization

N now supplies a richer exact entailment relation between typed obligations.

Define:

```text
A entails_N B
iff B subseteq Cl_N(A)
```

for appropriately typed positive obligation sets whose guards/resources/horizons are part of the facts.

Then one G proof term is redundant whenever another retained term is logically weaker under exact N entailment, not merely when its q-ID set is a literal subset.

This gives a candidate **N-quotiented prime-implicant antichain**:

```text
exact child-ID antichain
    -> no compression observed

typed obligations + N closure
    -> retain minimal terms under entailment
```

This is the most direct invariant-derived candidate for the missing proof normalization.

It must be falsified on guards, deadlines, resource conflicts and provenance before promotion.

## 5. Hidden common calculus D — parity defects and response-capacity defects both have circuits

The response-capacity projection already forms a transversal matroid when obligations are matched injectively to legal defender turns. Its invariant vocabulary is:

```text
rank
closure
circuits
fundamental circuits
exchange
deficiency
```

The linear dependency structure of GF(2) parity equations has the same generic matroid vocabulary:

```text
linear rank
closure of equations
minimal dependent sets / circuits
fundamental circuits relative to a basis
```

For affine equations an extra syndrome distinguishes two cases on a dependent circuit:

```text
syndrome 0 -> redundant consistent dependency
syndrome 1 -> parity contradiction
```

### Resolution

The parity system and response system are **not the same matroid**:

```text
P linear/binary dependence
C transversal/matching dependence
```

but their defect handling is isomorphic at the generic circuit level.

A reusable exact shell can therefore expose:

```text
rank
closure
fundamentalCircuit(addition, basis/independent-set)
defect witness
```

while leaving domain-specific semantics to P and C.

This suggests one general **circuit-driven defect-transfer operator**:

```text
attempt to add obligation/constraint
-> if independent: accept
-> if dependent: obtain minimal fundamental circuit
-> domain-specific resolution:
     P: redundant or contradiction by syndrome
     C: displace/transfer one resource obligation
```

This is stronger than merely noticing both systems have “capacity.”

## 7. Hidden quotient hierarchy F — trace congruence, residual congruence and output congruence factor through one another

There are several distinct ways histories become observationally equivalent.

### E-level trace congruence

Histories differing only by proved-independent, parity-preserving event interleavings may converge to the same colored physical state / exact q.

### R/Q-level residual congruence

Histories with different physical order can also become indistinguishable because they leave the same support and residual obligation structure.

### Output-sensitive refinement

Some value-equivalent histories are still distinguishable by original-line provenance, requiring `q+Pi0`.

Thus the useful picture is a chain of quotient maps rather than one quotient:

```text
legal histories
   -> parity-preserving trace classes
   -> value-residual behavior classes q
   -> W/D/L observation

legal histories
   -> ...
   -> output-sensitive classes q+Pi0
   -> terminal-line observation
```

Trace equivalence is therefore an **early congruence**; q is a future-behavior congruence; q+Pi0 is a refinement under a richer observation.

This explains why partial-order normalization can reduce pre-enumeration interleavings even when q itself shows no additional same-depth compression.

## 9. Hidden abstraction H — W/D/L intervals are an information completion of exact G values

The six W/D/L intervals are not another game-value system.

They are the nonempty convex subsets of:

```text

```

ordered by information refinement.

Exact singleton values embed into that domain, and structural certificates narrow information by interval intersection.

P0/P1 predecessor max/min lift monotonically to interval endpoints.

Thus the interval system is an **abstract information domain over G**, with exact G as its singleton subdomain.

This reinforces a useful separation:

