Worker topology is four deep workers, zero wide workers. The host rejects frontier/advisory deviations (`runtime/experiments/isomax-lean/host.mjs:28–47`). Shared TT uses a fresh zero-initialized `SharedArrayBuffer` (`runtime/experiments/isomax-lean/shared-cache.mjs:33–42`): 2^27 slots × 32 bytes = 4,294,967,296 bytes. The zero sequence word is a miss (`74–89`); exact values are inserted only during current-run computation (`92–109`). Private caches use fresh zero-initialized arrays (`solver-dense.mjs:26–33`): 2^24 tags × 4 bytes plus 2^24 keys × 32 bytes = 603,979,776 bytes per worker. Four private tables plus the shared table total 6,710,886,400 bytes before geometry, stack/scratch, Wasm control memory and Node overhead. First solve increments the initially empty private epoch (`solver-dense.mjs:105–108,330`); it does not load persisted entries.

`host.mjs:49–80` constructs root, shared geometry, TT, control/result/timing buffers and a fresh worker session per invocation. `worker-dense.mjs:10–36` attaches the shared cache, allocates fresh private solver state, and immediately invokes search. Worker order offset is index modulo column count (`worker-dense.mjs:28`); all four solve the same current root, sharing current-run exact values. The winner publishes through atomics (`worker-dense.mjs:58–66`). Host cleanup closes the session in `finally` (`host.mjs:101–106`). No persisted cache import occurs.

**Cold-check limitation:** the unchanged host exposes no all-workers-ready gate between private allocation and search, and worker modules immediately execute a solve. A wrapper cannot claim that an unrelated `--prepare-only` allocation inspected the later run's private TT buffers. Record fresh-buffer emptiness as a source-backed attestation unless a separately reviewed cold interception mechanism observes those exact allocations. Do not call the host or import an executable worker to implement a no-search preparation command. Any measured cold checks and behavior-load warmup count toward total process wall time; host `elapsedMs` starts after some allocation and is not total wall time.

## Computed trajectory and exact result scope

RLC takes the actual move array and prepared geometry, reconstructs occupancy/heights (`runtime/addons/connect4-rank-local-presearch.mjs:7–24`), detects terminal positions (`27–55`), measures legal landing live-line/denial counts (`57–93`), and selects a unique Pareto maximum only if column headroom remains (`95–147`). It has no imports and does not call search/CPC/oracle machinery. A wrapper must start with an empty array, repeatedly append the returned current-position move only while status is `CERTIFIED`, record every trace, and stop on `UNRESOLVED`. It must not insert a literal prefix, assume a fixed prefix length, or copy a published trajectory. This procedure is illustrated in `example.mjs:7–13` but that example is outside the benchmark dependency closure.

`CERTIFIED` identifies the implemented structural selection predicate. It does not prove that the selected action preserves minimax value. C4-0011 allows a composite run to begin empty, compute a live trajectory, and then search, provided its target is explicit. Therefore report **computed empty-start trajectory plus exact W/D/L and one value-preserving action at its live handoff position**. Do not relabel handoff WDL as an independently proved empty-root WDL, do not claim the prefix consists of optimal actions, and do not claim full-game self-play or a complete optimal-action set. Comparing its time with an external exact empty-root WDL solve must display this target difference.

The host converts absolute outcome encoding 1/2/3 to -1/0/+1 by subtracting two (`host.mjs:112`); `solver-dense.mjs:110–111` confirms the first-player absolute perspective. The live mover can differ from the first player. The returned `move` uses caller board coordinates and is zero-based; do not apply a second reflection. A valid outcome requires `status:'EXACT'`, valid WDL/move, clean worker completion, and the matching recorded handoff history; timeout/interruption/error cannot be parsed as exact. Native node counts are absent (`host.mjs:128–134`), so do not manufacture or equate them to an external solver's counters.
