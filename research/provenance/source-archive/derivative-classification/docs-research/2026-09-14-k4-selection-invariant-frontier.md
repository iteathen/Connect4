## Purpose

The board-family work now separates two questions that were previously entangled:

1. **structural classification** — which invariant objects are generated by `(W,H,K=4,gravity,turn parity)` before solving anything?

## 1. Canonical phase path

The line-side phase quotient is not merely an abstract copy of `Even(F2^W)`. It has a canonical realization as the edge space of the width-`W` column path graph

```text
0 -- 1 -- 2 -- ... -- W-1.
```

Let edge `i` join columns `i` and `i+1`. The GF(2) boundary map is

```text
partial(edge_i)=e_i+e_(i+1).
```

Because the column graph is a tree, this boundary map is injective. Its image is every even-weight column vector, hence

```text
F2^(W-1) ~= Even(F2^W) ~= C_phase.
```

Every CPC two-ply displacement

```text
e_a+e_b
```

has the unique path lift consisting of the adjacent edges between `a` and `b`. Therefore the canonical phase-transport length is

```text
lambda(a,b)=|a-b|.
```

Same-column two-ply play has empty lift and zero phase displacement. Horizontal reflection preserves the path boundary and transport length.

The columns minimizing worst-case phase transport are exactly the graph centers:

- one center when `W` is odd;
- two centers when `W` is even.

For `W=7`, the unique phase center is column 3 zero-based and the path radius is 3.

This is an exact structural theorem. **No claim is yet made that game-theoretic strong distance is monotone in `lambda`.** That implication would require CPC/NDC deadline semantics.

## 2. Initial legal-event requirement impact

On an empty board the only legal events are the bottom cells. For `K=4`, the bottom cell in column `c` belongs to

```text
d_W(c)
  = 1
  + h4_W(c)
  + I(c <= W-4)
  + I(c >= 3)
```

geometric winning lines, where `h4_W(c)` is the number of horizontal length-four intervals containing column `c`.

The terms are:

- one vertical line;
- horizontal intervals containing the cell;
- a rising diagonal endpoint when enough columns exist to its right;
- a falling diagonal endpoint when enough columns exist to its left.

A first move at that event advances exactly `d_W(c)` mover requirements by one cell and permanently blocks exactly `d_W(c)` opponent requirements. The count is therefore an exact local requirement-impact measure, although not yet an exact value function.

For all `W>=4`, the maximizing columns are

```text
W=4:  {0,3}
W=5:  {1,3}
W=6:  {2,3}
W=7:  {3}
W>=8: {3,4,...,W-4}.
```

Thus **`W=7` is the unique Connect-4 width whose empty board has one and only one maximum-impact initially legal event.** Its exact profile is

```text
[3,4,5,7,5,4,3].
```

At `W=7` that unique impact maximum is also the unique center of the canonical phase path.

## 3. Combined family classification recovers 7x6 and 28

The independently derived regular core imbalance is

```text
Delta(W,H)
  = dim(Y_line)-dim(Y_cell)
  = (W-4)(2H-9)-9.
```

Core balance requires

```text
Delta=0.
```

The unique-maximum initial-event invariant requires

```text
W=7.
```

Substitution gives

```text
(7-4)(2H-9)=9
3(2H-9)=9
H=6.
```

Therefore **7x6 is the unique regular K=4 board satisfying both**:

1. gravity-oriented line/cell core balance;
2. a unique maximally connected initially legal event.

The common core dimension then follows rather than being supplied:

```text
Y = WH-W-H-1
  = 42-7-6-1
  = 28.
```

This is a board-family derivation of why the standard geometry is structurally exceptional. It is stronger than observing that the isolated 7x6 incidence matrix happens to contain a 28-dimensional middle.

It still does **not** prove that distance-optimal play must choose the maximum-impact/phase-center event. That is the semantic selection step.

## 4. Preterminal exclusion capacity is useful but not the selector

For `K=4`, P0's natural preterminal rank is five plies. Define a purely static capacity:

```text
X_5(W,H)
  = maximum number of P0 maximal-delay support-envelope predicates
    already excluded by any legal five-ply prefix.
```

A line is excluded when it already contains a P1 stone, or all of its parity-capacity final-landing cells have already been consumed.

Exact finite audits give:

| board | P0 maximal-delay envelope | X5 | minimum survivors | Y_cell |
|---|---:|---:|---:|---:|
| 5x9 | 11 | 0 | 11 | 30 |
| 6x7 | 30 | 5 | 25 | 28 |
| 7x5 | 19 | 7 | 12 | 22 |
| 7x6 | 38 | 10 | 28 | 28 |
| 8x5 | 46 | 14 | 32 | 26 |
| 8x7 | 46 | 6 | 40 | 40 |
| 13x5 | 43 | 7 | 36 | 46 |

On 7x6 the maximum exclusion is uniquely realized by the five-high center stack, reproducing the standard `38-10=28` extremal lemma.

But **8x7 is a decisive falsifier of the scalar identity as a universal selector**:

```text
46-6 = 40 = Y_cell.
```

So

```text
minimum surviving maximal-delay envelope = Y_cell
```

is not sufficient to characterize the standard optimal terminal geometry.

The capacity remains useful input because it measures how much of a future deadline envelope can be changed before the earliest possible terminal rank. It must not be mistaken for the game objective.

## 5. Why simple terminal-envelope optimization is the wrong semantic rule

The terminal-line count is a **consequence** of strategic control, not obviously the quantity either player optimizes at early ranks.

A move can preserve many geometric terminal predicates while losing all deadlines that make them realizable, or can eliminate many predicates while creating a forced completion dependency. CPC explicitly warns that eventual ownership is weaker than ownership before an opponent completion deadline.

Therefore a board-family selector based only on

```text
line count
core dimension
maximal-delay support count
preterminal exclusion count
```

is structurally incomplete.

The missing information is temporal: response slots, event precedence, blocker certification and completion-before-opponent deadlines.

## 6. Candidate next invariant: deadline-valued NDC closure

C4-0007 already permits finite ranked dependency closure without legal-move-tree recursion. This suggests extending ordinary truth-valued NDC certificates with an exact **horizon**.

Conceptually, each certificate should carry

```text
(prerequisites, guards/resources, consequence, earliest/latest certified rank).
```

For a fixed proof polarity:

- an AND certificate becomes available no earlier than the maximum horizon of its prerequisites;
- alternative exact witnesses take the minimum available certified horizon;
- a blocker is relevant only when its certified horizon precedes the opponent requirement's completion horizon;
- release/reservation changes transport CPC phase through the canonical path representation, not merely an anonymous even-weight vector.

This is a tropical/min-max **proof-DAG** operation over exact dependencies, not recursive minimax over legal moves. Opponent universality still has to be represented explicitly through response/resource certificates; it must not be hidden inside an unqualified `max` operator.

The hoped-for board-parameterized selector is therefore not a scalar formula. It is a closure operator over

```text
I(W,H)
+ residual requirements
+ support/event order
+ phase-path transport
+ blocker/response resources
+ deadline horizons.
```

The selected terminal envelope would then be the set of requirements whose completion certificates survive that exact closure.

## 7. Current high-value theorem target

For standard 7x6, prove searchlessly that the initial unique event which is simultaneously

```text
unique maximum requirement impact
AND
unique phase-path center
```

is selected by the deadline-valued CPC/NDC closure, and that the opponent's strongest delay response preserves the same phase center until the rank-5 canonical stack is established.

A proof of that statement plus the already derived maximal-delay certificate would close the semantic gap to the target-free 28 envelope.

For other boards the same closure must naturally handle:

- multiple maximum-impact initial events;
- one or two phase centers;
- nonzero `Delta`;
- beta/gamma radicals and cokernels;
- different player-specific support horizons.

No special `if (W==7 && H==6)` branch is acceptable.
