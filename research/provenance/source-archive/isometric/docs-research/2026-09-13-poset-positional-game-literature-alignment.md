## Result

The event-poset interpretation developed in the current Connect4 research has a direct pre-existing mathematical home. We should reuse that terminology rather than inventing a new name for the gravity substrate.

## 1. Poset positional games

Bagan, Duchêne, Galliot, Gledel, Mikalački, Oijid, Parreau, and Stojaković introduced **poset positional games**: positional games in which a board element can be claimed only after all smaller elements in an additional partial order have already been claimed.

Primary sources:

- Guillaume Bagan et al., *Poset Positional Games*, FUN 2024, LIPIcs 291, 2:1–2:12, DOI `10.4230/LIPIcs.FUN.2024.2`.
- Expanded journal version: *Discrete Mathematics* 348(7), 114455 (2025), DOI `10.1016/j.disc.2025.114455`.

The paper explicitly uses **Connect 4** as a motivating example. More strongly, its section on posets that are a **union of disjoint chains** states that this case is a direct generalization of Connect-4.

For standard Connect Four, the gravity poset is exactly:

```text
7 disjoint chains, each of height 6
```

where within each column

```text
(c,1) < (c,2) < ... < (c,6).
```

A cell can be played exactly when all lower cells in its chain have already been claimed.

Therefore the current support model should be described, where useful, as a **poset positional-game substrate** rather than as a novel gravity formalism.

### Convention boundary

The Bagan et al. paper develops its strongest complexity results mainly for the Maker-Breaker convention. Standard Connect Four is an alternating strong/achievement game in which either player can complete a winning set first.

Consequently:

```text
poset substrate / terminology: directly reusable
Maker-Breaker outcome theorems: not automatically transferable
```

Any imported theorem must match the strong-game convention and terminal semantics before use.

## 2. Order ideals and linear extensions

The legal **support** configurations of standard 7x6 are precisely the finite order ideals of the disjoint-union-of-chains poset.

Equivalently, support is represented by the height vector

```text
(h1,...,h7), 0 <= hc <= 6,
```

and a legal move adds one minimal event from the complement of the current ideal.

This recovers the exact product-of-chains structure already identified in the current research.

A sequential play is a linear extension of the claimed-event order, additionally constrained by alternating player ownership. Thus the current phrase

```text
parity-colored linearization
```

is an appropriate refinement for the standard two-player turn convention.

## 3. Event-structure games

There is also established literature on **games and strategies as event structures**, notably:

- Simon Castellan, Pierre Clairambault, Silvain Rideau, and Glynn Winskel, *Games and Strategies as Event Structures*, Logical Methods in Computer Science 13(3), 2017, DOI `10.23638/LMCS-13(3:35)2017`.

This literature explicitly motivates causal/partial-order game representations as an alternative to sequential game trees that enumerate different interleavings of implicitly concurrent events.

That is structurally aligned with the present matrix-free direction:

```text
physical move tree
  = sequential interleaving expansion

causal event representation
  = partial order + choices/conflicts + winning observation
```

This does **not** mean the published concurrent-game semantics immediately solves Connect Four. It means there is mature formal machinery for the exact representational move we are considering: replace redundant interleaving histories by a causal event structure while retaining strategic polarity/choice.

## 4. Exact Connect4 correspondence now visible

The current bounded sibling control produced twelve cross-parent exact-q convergence points. They instantiate the local parity-preserving interchange


At the support level this is generated by the ordinary commuting diamonds of order ideals in a product/disjoint-chain poset. At the colored-game level, only interchanges that preserve player assignment are admissible without further bookkeeping.

So the current research is not merely metaphorically similar to concurrency theory. It contains an exact local confluence relation on the same kind of causal event substrate.

## 6. Immediate research implication

The next structural question should distinguish:

1. **causal branching** — genuinely different future event obligations or strategic choices;
2. **interleaving branching** — different legal schedules/linearizations of the same causal event set.

Exact q already merges many converged states after generation. A causal certificate could potentially quotient interleaving branching **before** enumerating it, while CPC/NDC/deadline/provenance guards preserve the strategic distinctions for which order really matters.

The earlier bounded proof-antichain control showed that exact-q child-set subset absorption itself gives zero compression on the four sibling controls. This literature alignment therefore strengthens the current conclusion: the next compression target should be the **causal/event obligation representation**, not a larger exact-state subset rule.

No complete standard-7x6 solve proof follows from this alignment alone.
