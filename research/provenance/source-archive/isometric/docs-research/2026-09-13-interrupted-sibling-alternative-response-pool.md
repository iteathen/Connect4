## 1. Sound base theorem: interval-separated sibling elimination

Let each exact child alternative `a` carry a sound W/D/L interval

```text
I(a) = [L(a), U(a)] subset_of {-1,0,+1}
```

with the interval semantics already owned by the current predecessor calculus.

For a P0/max predecessor, if two distinct exact alternatives `a` and `b` satisfy

```text
U(a) <= L(b)
```

then `a` is unnecessary for determining the parent maximum:

```text
max(V(a), V(b), ...) = max(V(b), ...)
```

because every value consistent with `a` is no greater than every value consistent with `b`.

Dually, for a P1/min predecessor, if

```text
L(a) >= U(b)
```

then `a` is unnecessary for determining the parent minimum:

```text
min(V(a), V(b), ...) = min(V(b), ...)
```

This is proof-obligation compression, **not state equality**. It requires no merge of C4-0010 `q` identities and is valid for any sound child intervals.

This theorem is worth retaining independently of the abandoned candidate family because it gives an exact bridge:

```text
structural certificate -> child interval -> sibling elimination -> exact PreE/PreA preservation
```

## 3. Candidate generated by the falsifier: even waiting-pool repair

A stronger response-policy idea emerged from the failure.

For columns with odd remaining capacity, treat each currently playable frontier cell as a member of a shared **waiting-resource pool** instead of simply leaving an unmatched cell behind.

Candidate policy shape:

```text
1. even-remainder columns use ordinary vertical response pairs;
2. odd-remainder columns expose their current playable bottom/frontier event into a waiting pool;
3. when the attacker consumes one waiting-pool event, the defender answers by consuming another compatible waiting-pool event;
4. the two affected odd columns then each have even remaining capacity and enter the ordinary vertical-pair regime;
5. ordinary vertical responses continue thereafter;
6. every attacker residual requirement must be intercepted by either a valid waiting-pool response or an ordinary vertical response before its completion deadline.
```

The important condition is that the waiting pool must itself admit a complete legal response pairing; the exploratory form used an **even waiting-pool cardinality** guard.

This is not yet accepted. A complete theorem would still need explicit proof of:

- legality of every waiting-pool response;
- totality for every attacker trigger order;
- no reuse of a consumed response resource;
- deadline safety;
- CPC/event-parity preservation under the pool-to-pair transition;
- WSL coverage of every live attacker requirement;
- NDC guard preservation;
- first-win/terminal ordering correctness.
