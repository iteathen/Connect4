## Strongest recursively exposed consequences

### 1. q_o / q_r / value are distinct quotient layers

The closure establishes:

```text
raw occurrence
    -> q_o orientation-sensitive future semantics
    -> q_r reflection-orbit future/value semantics
    -> scalar W/D/L
```

Each arrow may discard information.

The reverse implications are not generally available.

### 2. q_r is exactly a two-element reflection orbit quotient

Modulo q_o equality, q_r is the orbit quotient generated by horizontal reflection.

For finite q_o class count `N_o` and reflection-fixed count `F`:

```text
N_r = (N_o + F) / 2

ceil(N_o / 2) <= N_r <= N_o.
```

Therefore horizontal reflection alone can reduce semantic q-class count by at most a factor of two.

This does **not** bound the number of execution task occurrences that may map to one q_r class.

### 3. Scalar cache and action cache have different contracts

Exact scalar W/D/L is q_r-invariant.

Literal action labels are not.

Therefore:

```text
scalar q_r cache:
    no orientation payload needed for the scalar

action-bearing q_r cache:
    value-preserving witness required
    +
    identity/reflection transporter required
```

At q_o scope, literal action labels may be reused directly.

### 4. Advisory ordering is outside value semantics

EFFECT is reflection-equivariant.

PROMOTE is not generally reflection-equivariant because the fixed tie order:

```text
3,2,4,1,5,0,6
```

is orientation-sensitive.

This is not a scalar-value defect.

The primitive VALUE support graph does not depend on EFFECT or PROMOTE.

Any legal-action permutation preserves the mathematical max/min VALUE relation provided it changes neither the represented action set nor its outcomes.

### 5. Residual cofactor algebra is stronger than move-order freedom

BLOCK cofactors are idempotent and commute.

Guarded nonterminal OWN cofactors are idempotent/commuting under their exact domain.

Fixed-polarity OWN/BLOCK cofactors commute on distinct cells under the stated guards.

But this does **not** authorize reordering actual game moves because:

```text
alternating ownership
+ support progression
+ first-win stopping
```

remain load-bearing.

The first OWN_WIN is a hard composition barrier: no ordinary Q_STEP exists beyond that action.

### 6. Semantic and execution identity remain separate

Distinct task occurrences may project to the same q_o/q_r content.

Thus the system may share an established scalar VALUE while preserving:

- task occurrence identity;
- provenance;
- control state;
- execution lifetime.

QR_EQ cannot by itself retire a task or merge execution provenance.

### 7. The q dependency graph is finite and rank-well-founded

Every dependency edge increments support rank by one.

Therefore:

- no q dependency cycle exists;
- a path from rank n has at most `42-n` edges;
- same-rank nodes cannot reach one another by a nonempty dependency path;
- semantic q content space is finite.

A coarse q_o content bound is:


Finiteness is not a performance result.
