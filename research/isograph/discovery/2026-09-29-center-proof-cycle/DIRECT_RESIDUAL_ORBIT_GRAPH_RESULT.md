## Question

The physical 4x4 audit established:

~~~text
161,029 physical legal states
    -> 34,105 orientation-sensitive residual-q classes
    -> 10,507 residual-q column orbits
    ->  8,242 recursive action-unlabelled classes
~~~

This experiment asks whether the 10,507-state residual-orbit graph and the
8,242-class recursive quotient can instead be generated directly from the
empty-board structural state, using only the residual transition algebra.

## Direct producer

The producer begins with empty support and, for each player, the full set of
Connect-4 winning windows as the initial normalized residual antichain.

For each legal support action it:

1. obtains the landing cell from support;
2. positively cofactors the mover's residual requirements;
3. deletes opponent requirements blocked by that event;
4. normalizes duplicates and strict supersets;
5. stops immediately if the mover completes a requirement;
6. otherwise advances support;
7. canonicalizes support plus both residual antichains under all column-label permutations;
8. recurses only on the canonical residual state.

No token board or physical-state key is constructed. No minimax value is used
to decide which states or edges exist. W/D/L is derived only afterward as a
validation layer.

## Search-space reduction

Compared with 161,029 physical states, the direct structural graph contains
10,507 state nodes, about 6.5% as many. Compared with 304,574 physical legal
edges, it processes 31,669 literal residual-orbit action edges, about 10.4%
as many before duplicate equivalent actions are erased.

This is the first result in this campaign that reconstructs the full 4x4
action-unlabelled quotient without traversing the physical game graph.

## Interpretation

Previously, physical-graph -> recursive quotient could reasonably be treated
as compressed exhaustive semantics. The new construction is instead:

~~~text
root geometry
    -> residual antichain transition algebra
    -> column-action orbit graph
    -> recursive branch-local action quotient
~~~

and reaches the same 8,242 finite semantic classes without constructing the
physical boards. The quotient is therefore generated by the repository's
existing structural residual semantics plus action-label erasure, not merely
by physical-state enumeration.

## Remaining complexity burdens

This is still not a polynomial generalized Connect Four solution. The current
canonicalizer enumerates all column permutations (W!), and the residual-orbit
graph may itself grow exponentially with board dimensions.

~~~text
physical graph avoided
!=
polynomial generalized construction
~~~

The next burden is cross-dimension growth of the direct structural graph and a
compact canonical/refinement rule that avoids factorial action relabeling.

The direct residual graph uses between about 21% and 28% as many state nodes as
the physical graph on the tested Connect-3 controls, and only about 6.5% on
4x4 Connect-4. The result therefore survives width/height/K perturbation and is
not peculiar to one 4x4 C4 graph.

The gravity-orientation distinction is also preserved: 4x3 C3 and 3x4 C3 have
the same board area and raw winning-line count but produce different direct
residual-orbit graphs and different recursive class counts.

## Branch-local equivalence

The direct residual-orbit graph has 10,507 states but only 8,242 recursive
classes. A single static action permutation is therefore not the final quotient.
The remaining collapse is generated solely from successor-class sets, supporting
a branch-local transporter / bisimulation interpretation.

## Relation to XOR/GF(2)

No XOR claim follows directly. If GF(2)-like cancellation contributes to the
final value algebra, this result narrows the search to the smaller residual/
branch-local control system rather than literal physical move coordinates.

## Non-claims

This finite reconstruction does not prove a standard-7x6 closed form, a
generalized polynomial bound, an XOR W/D/L formula, or any production solver
change.
