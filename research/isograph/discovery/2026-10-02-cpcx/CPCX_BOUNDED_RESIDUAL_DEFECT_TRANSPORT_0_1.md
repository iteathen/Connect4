# CPCX bounded residual-defect transport 0.1

**Date:** 2026-10-03  
**Status:** theorem contract frozen before implementation  
**Scope:** experimental CPCX / RLC equivalence  
**Originating application:** turn-6 center-spine owner-exchange classes  
**Production CPC / solver:** unchanged

## Purpose

Formalize the smallest exact equivalence coordinate needed after the saturated-center
handoff.

Two positions need not have identical owner occupancy or identical live residual
families. If they have the same live support geometry and mover, their difference may be
represented as:

~~~text
common residual carrier C
+ left-only residual defect ΔL
+ right-only residual defect ΔR
~~~

with original winning-line identity retained.

The theorem states that under the same legal owner-labelled side event, common residuals
remain common and no new residual difference can be created from C. The defect is
transported only through residuals that were already different.

This is an exact transition statement, not a value statement.

## Objects

Let A and B be exact nonterminal positions on the same geometry with:

- identical support heights;
- identical mover;
- the same legal frontier cells;
- possibly different owners on already occupied cells.

For each position construct its exact owner-labelled live residual rows:

~~~text
(player, lineId, orientation, missingCells)
~~~

Retain lineId. Do not quotient different physical winning lines merely because they have
the same missing-cell set.

Define:

~~~text
C  = RA ∩ RB
ΔA = RA \ RB
ΔB = RB \ RA
~~~

using exact row identity.

The defect coordinate is:

~~~text
Δ(A,B) = (ΔA, ΔB)
~~~

Optionally canonicalize the entire pair under an already-qualified board symmetry.

## One-event theorem

Let e be the same current legal frontier cell in A and B. Because support and mover are
identical, e has the same owner label and is legal in both.

Apply the ordinary owner-labelled residual transition separately to A and B.

For every row r in C:

- if e is outside r, r is unchanged on both sides;
- if e belongs to r and the event owner equals r.player, the same cell is contracted on
  both sides;
- if e belongs to r and the event owner is the opponent, r is killed on both sides;
- if contraction completes r, the same original physical line completes on both sides.

Therefore no row originating in C can become a one-sided residual.

Hence before first-terminal stopping:

~~~text
Δ(A',B') ⊆ T_e(Δ(A,B))
~~~

where T_e applies the same line-wise residual cofactor/kill rule to the defect rows.

In particular:

~~~text
|Δ(A',B')| <= |Δ(A,B)|
~~~

when row multiplicity is keyed by original winning-line identity.

Equality is allowed. Defect rows may contract, die, complete, or converge and cancel.
They may not be created from the common carrier.

## First-win boundary

If an event completes a row in C, both positions expose the same winning line for the
same player on that event.

If terminal behavior differs between A and B, at least one completing line comes from
ΔA or ΔB. The theorem must report that as a defect-observable terminal divergence and
stop.

Thus the defect coordinate contains every source of first-win disagreement between the
paired systems.

The theorem does not erase terminal divergence.

## Multi-event corollary

By induction, for any fixed common legal event script before first terminal:

- support remains paired exactly;
- mover remains paired exactly;
- the common carrier evolves identically;
- the defect evolves only from its previous defect rows;
- defect cardinality never exceeds its initial line-indexed cardinality.

Therefore an initially bounded residual defect is a bounded exact continuation
coordinate under common event transport.

This is a finite transducer over the defect carrier, not a future-state search.

## Turn-6 specialization

After the rank-local handoff from 44444:

~~~text
44444 x 4
44444 4 x
~~~

have identical support and mover for each x != 4.

Their difference is generated by the fixed owner exchange on:

~~~text
{x1, D6}
~~~

After saturated-center cofactor compilation and exact reflection canonicalization, the
six off-center x values collapse to three initial residual-defect classes:

~~~text
distance 1: x in {3,5}
distance 2: x in {2,6}
distance 3: x in {1,7}
~~~

The mechanically observed exact line-indexed symmetric-difference sizes are bounded by
18 residual rows.

The candidate constrained state identity is therefore:

~~~text
saturated-center base cofactor
+ side support
+ mover
+ reflection-canonical bounded residual defect Δ
~~~

rather than full physical owner occupancy.

## Polynomial consequence

For N physical winning lines of size K:

~~~text
construct common/defect partition: O(N*K)
transport one event:              O(|Δ|*K + incident common rows*K)
~~~

For fixed Connect Four K=4. At the turn-6 handoff |Δ| is bounded by a constant-size
geometry-derived defect family.

No legal-reply tree, minimax, solved value, opening book or oracle is required.

## What remains after qualification

This theorem would establish that the geometry correction is an exact bounded
transition coordinate.

It would not yet prove that all three turn-6 defect classes have the same game value or
strong distance.

The next proof target would be one of:

1. a single RLC/RCIC policy expressed over the base cofactor plus Δ;
2. a defect-normalization theorem routing all three Δ classes into one known
   certificate class;
3. a proof that the relevant continuation claim is insensitive to Δ after a bounded
   structural transform.

Failure of those stronger statements would narrow the equivalence further; it would not
invalidate bounded defect transport itself.

## Required qualification

1. a fresh same-support pair with empty defect;
2. a fresh pair with one owner-induced residual defect;
3. contraction of a defect row;
4. killing of a defect row;
5. convergence/cancellation of defect rows if a fixture is available;
6. common-row contraction remains common;
7. common-row kill remains common;
8. terminal divergence is reported only from a defect row;
9. all six turn-6 owner-exchange pairs;
10. production CPC / solver / oracle / recursive-search isolation.
