## Observed seam

At the remaining Class-C post-macro controller state, the strongest candidates
are P0 `D6` and P0 `G4`, both with singleton target `C3` and root reservoir
coverage gap 2.

For both candidates the current universal P1 trigger `B3` has no admitted
selected repair under reservoir-gap RCIC v0.1.

The structurally natural response `P0:B4` is already generated by the frozen
partial reservoir template. Its child has exactly the same obstruction
descriptor as its parent:

```
minimumUncoveredResiduals
uncoveredMissingCellMass
uncoveredSupportDebtSum
uncoveredSupportDebtMax
descendingSupportDebtVector
```

but two physical events have been consumed.

The current RCIC rejects that edge solely as:

```
COVERAGE_RANK_NOT_DECREASING
```

## Hypothesis

The obstruction descriptor is incomplete for neutral/stuttering reservoir
transport.

Extend it by the already-established finite structural resource:

```
remainingCapacity = boardCellCount - rank
```

as the **last** lexicographic coordinate.

Candidate rank:

```
(
  minimumUncoveredResiduals,
  uncoveredMissingCellMass,
  uncoveredSupportDebtSum,
  uncoveredSupportDebtMax,
  descendingSupportDebtVector,
  remainingCapacity
)
```

Lower is better.

Thus a response that preserves the entire reservoir obstruction but consumes
physical capacity is strict progress.

## Why this coordinate is admissible

Remaining capacity is:

- current-state and rank-local;
- independent of solved outcome;
- finite and nonnegative;
- strictly decreased by every two-event opponent/controller transaction;
- already used as the final coordinate in the qualified protected-diagonal
  response-descent measure
  `(missingCount, supportDebt, remainingCapacity)`.

This is not a remoteness objective. It is only a well-foundedness resource for
the proof recurrence.

## Falsifier

The hypothesis fails if the extended rank still leaves either Class-C
`D6 -> C3` or `G4 -> C3` non-response-total.

In particular, a later state with a current P1 terminal remains an absolute
failure; decreasing remaining capacity may not override first-win precedence.

Preserve such a failure rather than adding exceptions.
