# CPCX Class-C Support-Release Reservation Diagnostic Design 0.1

**Branch:** `experiment/cpcx-20261002`

## Purpose

Test whether the persistent Class-C gap-1 opponent singleton at `C2` is
already covered by the qualified CPCX support-release response-neutralization
theorem, but is being lost because the reservoir-gap RCIC carries only a scalar
obstruction descriptor and not the theorem's guarded response reservation.

This is a compatibility diagnostic only. It does not yet modify the RCIC.

## Exact timing distinction

Reservoir-gap nodes are P1-to-move boundaries.

The existing support-release theorem is **not** invoked directly at such a
boundary. It applies one half-step earlier:

```
P1 current event e
-> exact child with P0 to move
-> selected P0 event d
-> new P1 boundary
```

At the P0-to-move intermediate state after `e`, the theorem may certify that
the selected P0 event `d` leaves a depth-one P1 singleton target `t`
guarded by the reservation:

```
P1 supplies support(t) -> P0 occupies t
```

while every other P1 event is in the theorem's EXTERNAL class.

Thus the relevant possible missing state is not another scalar rank coordinate.
It is a **guarded response-reservation token** attached to a qualified P0
transition.

## Consumed theorem

Use only:

`certifyCpcxSupportReleaseResponseNeutralization`

from:

`cpcx-support-release-neutralization.mjs`.

Do not weaken its premises.

## Cohort

Consume the exact Class-C D6/G4 reservoir-gap structural DAGs already generated
by the current diagnostic.

Restrict attention to exact P1-to-move gap nodes containing a live P1 singleton
whose unique target is `C2` at support distance one.

For each current P1 event at such a node:

1. apply that exact P1 event;
2. stop if P1 terminals;
3. otherwise inspect the exact P0-to-move child;
4. reconstruct the still-live P1 `C2` singleton if present;
5. enumerate only the **current legal P0 frontier** at that child;
6. for each current P0 action `d`, invoke the qualified support-release
   neutralization theorem;
7. record exact positive and negative seams.

This is one current P1 frontier plus one current P0 existential frontier. No
later free P1 frontier is generated by the diagnostic; the support-release
theorem itself handles its SUPPLY/EXTERNAL partition symbolically.

## Primary question

Does every nonterminal current P1 event in the relevant Class-C gap-1 cohort
admit at least one current P0 event that simultaneously:

- is legal and nonterminal under the theorem;
- leaves the P1 `C2` singleton at support distance one;
- certifies the exact support-release reservation;
- preserves first-win precedence?

If yes, the reservoir recurrence is missing a theorem-backed state token rather
than an arbitrary new response move.

## Special current supply event

If the observed current P1 event itself is the support cell `C1`, the
support-release theorem cannot retroactively apply from that same node.

Record this case separately.

A later composition may consume it only if the predecessor P0 transition
already carried the reservation token.

The diagnostic must therefore report:

- current-supply rows;
- whether those rows have a predecessor edge in the same Class-C RCIC for which
  the reservation was certified when that predecessor P0 response was chosen.

No such predecessor composition is claimed by this diagnostic.

## Output

Report separately for D6 and G4:

- exact gap-1 state count with P1 C2 at support distance one;
- current P1 event count;
- P1 terminal event count;
- current-supply `C1` count;
- nonterminal/non-supply event count;
- count with at least one support-release-qualified current P0 action;
- qualified P0 action labels and theorem provenance;
- negative seam histogram;
- whether all nonterminal/non-supply rows are covered.

## Falsifiers

Preserve a negative result if:

- a nonterminal/non-supply P1 event has no qualified P0 reservation action;
- the C2 residual is destroyed or changes support class unexpectedly;
- a candidate P0 action creates a P1 immediate terminal;
- the theorem reports multiple urgent P1 singleton targets after supply;
- post-block transport creates another immediate P1 singleton;
- the current-supply rows cannot be related to a predecessor reservation
  without adding future search.

## Search boundary

Allowed:

- current P1 frontier quantification;
- current P0 frontier existential audit;
- one exact theorem call per current P0 action;
- deterministic theorem-internal supply/response audit.

Forbidden:

- recursive arbitrary legal-move traversal;
- solved values;
- oracle labels;
- best-move labels;
- minimax / negamax / alpha-beta;
- remoteness.

Production CPC and the production solver remain unchanged.
