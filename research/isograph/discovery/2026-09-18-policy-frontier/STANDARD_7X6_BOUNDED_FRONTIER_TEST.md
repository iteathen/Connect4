# Standard 7x6 bounded action-value frontier test

**Date:** 2026-09-18  
**Status:** bounded sampled 7x6 qualification evidence; not exhaustive standard-board authority  
**Parent campaign:** `research/isograph/discovery/2026-09-18-policy-frontier/`  
**Frozen authority 1.1 mutated:** no

## Question

Does the support-local favorable residual order remain useful on the real standard 7x6 board, and can independently constructed next-rank value frontiers determine exact best moves without searching the held-out continuation?

The test deliberately separates three questions:

1. **isotony:** does the favorable residual order ever reverse exact state/action value?
2. **frontier compression:** do exact score regions admit materially smaller antichain boundaries?
3. **constructive move selection:** can frontiers built from independent child states choose the exact best move in unseen parent states using only one legal transition plus frontier membership?

## Environment and scope

The experiment used the repository Pons-style exact 7x6 recurrence from `components/oracle/exact7x6.mjs`, reproduced in a standalone Node control.

Runtime used for the research run:

~~~text
Node.js v22.16.0
standard board 7x6 connect-4
first-win stopping
exact strong score:
    W/D/L first
    fastest forced win
    longest forced loss
~~~

Timings are **not** production benchmark claims. The result is about exact classifications/counts.

State coverage is deterministic sampled coverage, not exhaustive 7x6 coverage. Nonterminal legal states were generated by seeded legal play with physical-state deduplication. Every sampled position and action label was evaluated by the exact oracle.

## 4. Cross-rank constructive test

This is the more important test.

For each parent rank r:

1. independently generate/solve child states at rank r+1;
2. construct **state-value** threshold frontiers only at rank r+1;
3. independently generate unseen parent states at rank r;
4. for each legal parent action:
   - apply the exact one-move transition;
   - query the child state against the rank-(r+1) frontiers;
   - negate the exact/bounded child score interval into the parent action interval;
5. choose a best move only when the resulting intervals prove the exact argmax;
6. compare against independent exact-oracle action scores.

Thus parent best moves are **not** used to construct the frontiers.

## 5. Coverage-budget scaling

The low-rank weakness at a 20k child budget is dominated by missing/sparse child-support frontiers.

Two child-budget scaling controls were run.

### Parent rank 28

~~~text
child frontier budget       20,000 -> 100,000 states
unknown child-support hits   5,965 ->     607
exact best-move coverage     30.44% -> 73.36%
false best-move claims            0 -> 0
~~~

### Parent rank 26

~~~text
child frontier budget       20,000 -> 100,000 states
unknown child-support hits   9,373 ->   1,434
exact best-move coverage     15.40% -> 61.36%
false best-move claims            0 -> 0
~~~

This materially changes the interpretation of the lower-rank decline.

The observed failure mode is primarily **frontier/support coverage**, not a detected failure of the favorable-order relation.

## 6. What this demonstrates

The experiment now goes beyond compression of already-solved states.

It demonstrates a bounded constructive procedure on standard 7x6:

~~~text
rank-(r+1) exact state-value frontier
        +
one exact legal q transition
        |
        v
parent action score interval
        |
        v
argmax proof
        |
        v
exact best move at rank r
~~~

On independently sampled parent states this procedure frequently chooses the exact best move **without solving the held-out continuation**, and it has produced no false move claim in the tested sample.

That is the first direct bounded evidence that the frontier relation can act as a solver method rather than only a storage compression.

## 7. What is not established

This does **not** establish:

- exhaustive standard-7x6 frontier correctness;
- empty-root solution from these sampled frontiers;
- that frontier generator count remains tractable to rank 0;
- that random support sampling is an efficient construction algorithm;
- that current JS generator construction is performant;
- that the isotony theorem candidate has completed independent proof review.

The current random frontier builder is intentionally a qualification harness, not the proposed implementation.

## 8. Methodological consequence

The next problem is no longer:

> does the relation work at all on 7x6?

The sampled evidence is strongly positive.

The next problem is:

> how do we construct a sufficiently complete frontier cheaply as rank decreases?

That points directly toward combining the existing methods:

- BSFP-style backward propagation should construct/minimize frontier generators;
- IsoMax-style demand should request only support/action thresholds relevant to the current root proof;
- guarded structural certificates should inject additional exact generators/bounds;
- SUT may naturally become demand-driven consumption of a supply-driven frontier.
