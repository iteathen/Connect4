## DP-28 — Dimensional / unit structure

PASS; one measurement defect is made explicit.

Several current metrics live in different units and must not be collapsed:

```text
recursive nodes
manager q nodes
submitted tasks
worker runTask execution milliseconds
worker turnaround milliseconds
manager wall time
sampled/static JIT sites
bytes / RSS / heap / external memory
q rank / ply
```

In particular, worker `executionMs` is measured around `solver.runTask(message)` and therefore excludes:
- `process.memoryUsage()`;
- result object construction;
- `postMessage` serialization/transport.

Thus `executionMs` is not full task service time. This matters both for F-004 and for any #94 structural-cost model.

QU refinement:

```text
QU-HOT-03B — task service-time decomposition

known:
    worker recursive executionMs
    manager wall time
    task counts

open:
    result-side memory census cost
    result serialization/transport cost
    queue/dispatch turnaround
    contribution of each to critical-path idle time
```

Do not interpret static generated-code site counts as dynamic instruction counts; QU-HOT-02 remains.

## DP-30 — Reachability / connectivity structure

PASS with stronger reachability ownership for F-002.

The generic WSL residual kernel admits many syntactically valid class/cell combinations that do not occur at the scoped solver edge after frontier closure.

The worker-reachable subset satisfies:

```text
quiet or native-forced ongoing state
+ legal landing
    ->
no own singleton on landing
    ->
nonterminal mover cofactor
```

Optimization must be scoped to this reachable edge family. General residual APIs still require terminal-capable behavior.

No larger global “reachable residual class” restriction is inferred; class interning remains general enough for reflection, diagnostics and supported construction paths.

## DP-31 — Conservation / balance structure

PASS; no new candidate.

The reversible kernel conserves the exact parent state through every child exploration:

```text
applyUnchecked(column)
    -> child work
    -> undo()
    -> exact parent restoration
```

This conservation law is what makes F-006 safe in principle: one manager parent replay can serve all sibling q derivations through apply/undo rather than full reconstruction.

Prepared q coordinates are copied into scalar locals before descendant recursion because shared scratch is not conserved across calls; this retained design remains necessary.

Unfinished/retired work still conserves the rule “no exact value publication.”

## DP-33 — Degenerate / special-case structure

PASS with one conceptual strengthening of #95.

A dependency edge is deterministic whenever the current ordinary state has exactly one legal successor, regardless of *why*:

```text
native forced-response theorem
OR
legal action outdegree == 1
    ->
one ordinary value dependency
```

Current #95 describes manager-visible forced chains primarily through native forced consequences. The deeper semantic object is a chain of **outdegree-one q dependencies**.

**F-007 — decision-frontier macro edges should be defined by exact ordinary outdegree 1, not only threat-forced classification.**

Examples:
- one exact forced defense;
- late positions with only one non-full/legal column;
- any future exact rule that reduces the ordinary action set to one successor.

This can strengthen #95 without a new issue. It does not mean the worker must scan for unique legal action at every node if the detection cost exceeds saved work.

At the recursive level, a one-legal-move state can also bypass advisory move ordering, but frequency/economics must be measured before adding a hot branch.

Other special cases remain owned:
- terminal before q: #98;
- support/reflection stabilizer: #97;
- bilateral/one-sided residual exhaustion: retained native/bound work;
- empty certificate bypass: retained.

## DP-34 — Failure-mode correspondence

PASS; fail-closed behavior remains outside optimization authority.

Required failure distinctions include:
- sealed residual/chunk/class/cache capacity errors;
- invalid external certificate forced cell;
- native/certificate contradiction;
- worker poisoning/fault;
- abort;
- task retirement;
- timeout;
- malformed result.

F-002 cannot remove general residual terminal handling.
F-005 cannot weaken certificate validation.
F-006 must preserve apply/undo restoration on every exceptional path.
F-004 cannot remove resource diagnostics if they are required by an external contract without an explicit replacement.

No optimization may convert a capacity failure into recursive growth.

## DP-35 — Exception-structure discovery

PASS; no exception-removal candidate survives.

The recursive `try/finally` around apply/undo is structurally necessary because task quantum, retirement, abort and errors unwind through recursion.

Precreated `quantumEnd` and `taskRetired` sentinels already avoid allocating Error objects for normal control exits.

Diagnostic string/error construction remains failure-only.

Do not remove `try/finally` merely because ordinary successful recursion does not throw.

F-005 is specifically about avoiding a proof-facing validator when provenance proves it unnecessary; it does not remove the validator or its exceptions from the certificate path.

## DP-36 — Representation-redundancy discovery

PASS with consolidation, not a new broad rewrite.

Current real redundancies/candidates are already sharply owned:

- unsigned/signed operation-word conversions: #96;
- residual-first mirror selection when support may decide orientation: #97;
- q derivation before terminal classification: #98;
- repeated residual word loads in pair incidence: #99;
- dense class copy before immediate transform: #100;
- generic JS payload array for WDL-only workers: #101;
- full child replay from history despite live parent state: F-006 -> #85;
- full memory census per result: F-004;
- repeated terminal-capable mover checks after frontier excludes terminal: F-002 -> #100 family;
- proof-facing native forced-cell validation after exact native provenance: F-005 -> #86/#87 family.

Negative redundancy results:
- `sideToMove`, `status`, heights, support masks, playable masks and packed support are semantically related but have independent fast/public consumers; do not remove them by algebra alone.
- manager parent Sets/edge objects are not automatically the bottleneck; #85 measured manager share and rejected an epoch rewrite.
- worker replay is required at the portability boundary even though manager-local child replay can be removed.
- cache `used` and payload representation should be revisited only within #101-style specialized WDL experiments; do not narrow the generic object-valued cache.
