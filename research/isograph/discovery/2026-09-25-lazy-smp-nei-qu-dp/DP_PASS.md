# Lazy SMP Discovery Protocol — DP-01 through DP-45

**Status:** COMPLETE

## DP-01 — Cross-boundary relational structure
PASS. Private worker search crosses only into optional shared exact evidence; partial recursion state stays private.

## DP-02 — Constraint-structure discovery
PASS. Correctness requires complete private exact solving, exact-only shared publication, fail-closed reads, and exact first-finisher acceptance.

## DP-03 — Interface / port correspondence
PASS. Host supplies common root/geometry/shared cache; workers publish exact result/metrics; shared exact cache is the only search-evidence bridge.

## DP-04 — Dependency-topology discovery
PASS. One semantic dependency is materialized as N private demand traversals plus shared exact-fact reuse; no partition ownership exists.

## DP-05 — QU / open-region topology
PASS. Open regions localize to diversity, overlap, density/capacity, scaling, replacement, witness distribution, and key-to-q mapping.

## DP-06 — Repeated relational motifs
PASS. Every worker repeats local probe -> optional shared probe -> recurse/evaluate -> local exact publish -> optional shared exact publish.

## DP-07 — Alternative-factorization discovery
PASS. Method factorizes into private correctness core, optional acceleration layer, and first-exact termination.

## DP-08 — Residual structure after partial match
PASS. Removing shared cache leaves complete private exact workers; removing private completeness destroys correctness ownership.

## DP-09 — Symmetry / automorphism discovery
PASS. Workers are role-symmetric under worker/policy permutation; this is separate from board-reflection q_r.

## DP-10 — Role-equivalent elements under different labels
PASS. Workers are role-equivalent but execution-occurrence distinct.

## DP-11 — Invariants across admissible variation
PASS. Root exact W/D/L, legality, first-win semantics, private completeness, and fail-closed cleanup survive scheduling/interleaving variation.

## DP-12 — Known/unknown interface correspondence
PASS. Shared cache contains known exact facts; unfinished progress/bounds/future usefulness are not promoted as shared exact knowledge.

## DP-13 — Multi-scale common substructure
PASS. The same exact recurrence exists at node, worker, and whole-run scales; worker count changes materialization only.

## DP-14 — Transformation-invariant discovery
PASS. Permuting worker occurrences and their assigned policies preserves exact root value, not necessarily runtime/winner/witness.

## DP-15 — Information-flow structure
PASS. Root flows host->workers; exact facts worker->shared->workers; exact root result winner->host; stop host/control->workers.

## DP-16 — Causal / temporal structure
PASS. Reuse is temporally gated by exact derivation then publication; visibility delay changes economics, not semantics.

## DP-17 — Containment / ownership structure
PASS. Recursive state/local cache are worker-owned; shared cache/control/results are shared realization objects, not game identities.

## DP-18 — Cardinality / multiplicity structure
PASS. Worker count is 2..64; ordering diversity repeats modulo columns, so policy multiplicity can be lower than worker multiplicity.

## DP-19 — Dual / reversed structures
PASS. Workers discover dependencies forward and return values backward; shared cache creates exact-fact read/write duality.

## DP-20 — Complement / exclusion structure
PASS. Miss/eviction/contention excludes reuse opportunity, not correctness; partial non-exact information is excluded from sharing.

## DP-21 — Fixed-point / recurrence structure
PASS. Lazy SMP introduces no new game recurrence; every worker runs the unchanged exact solver recurrence.

## DP-22 — Compositional-structure discovery
PASS. N complete evaluators + exact-fact reuse + first-exact termination compose the search method.

## DP-23 — Reconstruction-structure discovery
PASS. Any worker can reconstruct exact root value alone; shared evidence accelerates but is not required evidence.

## DP-24 — Proof / witness topology

## DP-25 — Refinement-relation discovery

## DP-26 — Boundary-movement invariance

## DP-27 — Parameter-role correspondence
PASS. workers controls occurrence multiplicity; mask controls shared density; capacities control materialization; orderOffset controls traversal order.

## DP-28 — Dimensional / unit structure
PASS. Nodes, wall, CPU, cycles, cache hits/stores, bytes, workers, and completion counts remain distinct quantities.

## DP-29 — Ordering / partial-order structure
PASS. Action order is advisory traversal order, not semantic value ordering.

## DP-30 — Reachability / connectivity structure
PASS. Shared fact helps only if another worker reaches its corresponding key after publication and before replacement.

## Synthesis

Lazy SMP is a decentralized evaluation policy over one exact value dependency. Its optimization mechanism is traversal diversity plus opportunistic exact-fact reuse, not semantic partition. The strongest remaining questions are economic: useful diversity, pre-publication overlap, fact leverage, sharing density/capacity/replacement, worker scaling, and implementation-key placement relative to q_o/q_r.
