## Correction

Version 0.1 retained too much semantic labeling. The target is not the identity of
three channels, the names of their carriers, or the historical path by which a
three-way configuration formed.

The target is the **anonymous transaction law** among three mutually coupled
relations.

All comparisons in this experiment therefore quotient:

- object identity;
- board coordinate labels;
- carrier/certificate names;
- orientation/reflection labels;
- the order in which the three roles were discovered;
- domain-specific interpretation of each role.

Only relational transaction topology remains.

## Anonymous triadic object

Let three current role values be

```
v = (v1,v2,v3)
```

with the three pair relations

```
d12 = v2-v1
d13 = v3-v1
d23 = v3-v2.
```

The exact circuit identity is

```
d12 + d23 - d13 = 0.
```

Thus the visible triangle contains three pair-relations but only two independent
relative degrees of freedom.

Any simultaneous relabeling by S3 is the same anonymous state.

For non-scalar role values, subtraction is interpreted in the frozen ambient
abelian coordinate group; only equality/change incidence is required by the
first test.

## Transaction motifs

### T0 — stutter

No role changes and no pair relation changes.

### T1 — single-role transaction

Exactly one role changes. Therefore exactly the two incident pair relations
change and the opposite pair relation is invariant.

Anonymous incidence signature:

```
changed roles = 1
changed pair relations = 2
```

The identity of the changed role is discarded.

### T2 — coupled two-role transaction

Exactly two roles change and all three pair relations may change.

Anonymous incidence signature:

```
changed roles = 2
changed pair relations = 2 or 3
```

### TR — rearrangement / re-coordination

An intervention destroys the current concrete carrier, but the unresolved
relational state is reconstructed on a new carrier that preserves a nonempty
overlap/inheritance relation with the old carrier.

The identities of old/new carriers are discarded. Record only:

- source carrier destroyed;
- replacement candidate count;
- inherited/overlap cardinality;
- whether the replacement is structurally lower under the already-frozen
  well-founded order.

### TT — terminal realization

The relational defect is realized terminally rather than transferred.

## First-pass comparison

The first pass asks only:

1. Does each system carry an exact three-pair circuit with one dependency?
2. Are local nonterminal interventions dominated by T1:
   one changed role -> two changed pair relations?
3. Does either system exhibit TR:
   concrete carrier destruction followed by relational re-coordination?
4. Does a purely independent/first-order description fail where pairwise or
   higher interaction succeeds?

A positive answer is evidence for a shared **triadic relational transaction
kernel**.

It is not yet an isomorphism theorem.

## Strong falsifiers

Reject or narrow the hypothesis if:

- the apparent triangle disappears when labels are quotiented;
- transition classification depends on which named channel is called 1/2/3;
- CPCX requires four or more independent relational roles in every faithful
  normalization;
- the historical circuit is only a notation identity and has no corresponding
  local transaction incidence;
- re-coordination depends on exact carrier names rather than an inherited
  relation;
- apparent coupling vanishes under S3 canonicalization.

## Claim boundary

A positive first-pass result establishes only that independent UC4A/CPC and
current CPCX data exhibit the same anonymous low-level transaction motif:

```
three pair relations
+ one circuit dependency
+ local off-diagonal redistribution
+ possible carrier re-coordination.
```

It does not establish:
- Newtonian three-body equivalence;
- Faddeev-equation equivalence;
- computational irreducibility;
- undecidability;
- rank-local remoteness impossibility;
- turn-6 strong-perfect play.
