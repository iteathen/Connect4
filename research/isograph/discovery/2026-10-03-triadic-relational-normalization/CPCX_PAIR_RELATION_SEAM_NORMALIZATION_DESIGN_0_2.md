# CPCX pair-relation seam normalization 0.2

**Date:** 2026-10-03
**Status:** frozen before execution
**Parent:** TRIADIC_RELATIONAL_NORMALIZATION_EXPERIMENT_DESIGN_0_1.md

## Purpose

Test the stronger hypothesis suggested by the archived late-XOR/CPC bridge:

The relevant triadic object is not three independent state variables but three
**pair relations** among three primitive roles.

For CPCX define the primitive roles independently of certificate names:

- **K — carrier / completion requirement:** which residual/target relation carries the unresolved completion condition.
- **S — support / release state:** accessibility, support debt, event phase, release depth.
- **R — response / guard state:** opponent blocking capacity, immediate counterterminal interface, forced-response reservation.

The anonymous pair channels are:

- **KS:** carrier-support coupling;
- **KR:** carrier-response coupling;
- **SR:** support-response coupling.

## Frozen semantic classification

Classify only exact/current CPCX objects from the already-existing endpoint diagnostic.

### KR — carrier-response transfer

- same-track protected-target transfer;
- anchor-pivot transfer;
- target-inheritance handoff.

These are admitted only because an opponent response acts on a protected target
and changes which carrier represents the unresolved condition.

### KS — carrier-support progress

- protected support advance;
- protected target acquisition;
- ordinary controller descent when the trace explicitly identifies support
  advance or target acquisition.

These change/reduce completion accessibility relative to the current carrier.

### SR — support-response transport

- exact forced response;
- protected forced normalization;
- forced normalization;
- opponent-singleton release hazard.

These are support/release events whose admissibility is determined by the
response/counterterminal interface.

### KSR — genuine three-way coupling

- playable-target fallback triggered specifically by a support release that
  would create an opponent singleton;
- vertical staged progress whose first-win guard is partitioned by defender
  response hazards;
- latent-singleton pair-hub overload or its normalization handoff when present
  in the current diagnostic/progress source.

Do not infer KSR merely because a high-level composition calls several lemmas.

## Sequential handoff test

For each consumed no-transfer target-block seam, project the exact diagnostic
chain in execution order where available:

1. protected-target block / carrier handoff;
2. selected carrier progress action;
3. immediate response/guard classification;
4. deterministic normalization or saturation trace;
5. next progress class / terminal class.

Collapse consecutive repeats of the same pair channel.

Report the resulting channel words, e.g.

`KR -> KS -> SR -> KS`

without interpreting any particular word as a theorem.

## Comparison target

The archived exchange-phase bridge is independent evidence that a three-channel
system can be represented by the three pair relations among local channels and
that its pair-delta circuits close.

This test asks only whether the current CPCX moving seam is naturally expressed
as repeated transitions among all three pair channels rather than as monotone
progress in one fixed pair.

## Strong positive signal

- KR, KS, and SR all occur in exact consumed seams;
- at least one seam word visits all three;
- at least one word returns to a previously active pair after visiting another;
- KSR appears only at structurally genuine coupling points rather than being
  assigned broadly.

## Falsifier

If the consumed seam reduces to a single pair channel plus bookkeeping, the
triadic rearrangement hypothesis is weakened.

No W/D/L, oracle, solved score, or three-body premise is used.
