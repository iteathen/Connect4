# Research history

History is retained because negative and superseded knowledge constrains future work.

- `disproven/` — proposition is false under its stated scope.
- `rejected/` — approach was evaluated and intentionally rejected under current constraints/evidence; underlying propositions may remain true.
- `superseded/` — later work replaces the formulation/evidence packet.
- `historical-only/` — lineage/context that should not drive current reasoning.
  - `historical-only/solver-lineages/` — retired solver-family knowledge, final branch heads, useful mechanisms, measurements, and reasons for retirement.

Never put an exact theorem in `rejected/` merely because one implementation of it was slow or unproductive.
