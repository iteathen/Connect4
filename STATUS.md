### 1. Unique critical column

Horizontal reflection sends `c -> W-1-c`. Because `W` is odd there is exactly one fixed column:

```text
c*=(W-1)/2.
```

Thus the center is generated by empty-board symmetry rather than supplied as an opening-book move.

### 2. Natural preterminal rank

P0's earliest possible K-stone terminal is ply

```text

```

The preceding P0 move is therefore the natural preterminal rank

```text

```

At that rank P0 owns `K-1` events and P1 owns `K-2` events.

### 3. Canonical P chain

For the unique reflection-fixed column, each complete two-ply same-column pair is a native CPC phase stutter:

```text

```

Two such pairs followed by P0's preterminal event generate the five-cell alternating critical stack:

```text

P0, P1, P0, P1, P0.
```

This stack is constructed from symmetry, gravity, turn parity and `P`; it is not imported from issue #41.

### 4. Structural maximal-delay boundary

The board has `WH=42` cells. P0 moves on odd one-based plies, so the latest **possible** P0 terminal is the largest odd ply not exceeding capacity:


`T_max` is a structural capacity boundary only. The current target-free theorem does **not** yet claim that optimal P1 defense can attain it.
