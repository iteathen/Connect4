# Optimal-play 28-line oracle / incidence audit

**Research direction / structural architecture / invariant-first and self-proving-predicate program:** Josh Oshiro  
**Formalization / implementation / qualification:** OpenAI ChatGPT

## Scope

Repository issue #41 supplies external solved-oracle evidence that exactly 28 geometric winning lines occur under distance-sensitive optimal play from the empty standard 7x6 board. The issue also records the earlier 61-line W/D/L-only experiment.

This note is validation evidence only. The solved-data premises are not inserted into the target-free GF(2) theorem that independently derives the common 28-dimensional middle object from `GF(2), K=4, H=6, W=7`.

## Why 61 appeared first

Under W/D/L-only scoring every P1 continuation at a theoretically lost position has value `-1`. A traversal that treats tied W/D/L values as equally optimal therefore admits both longest-resistance defense and strategically inferior faster losses. That broadens the terminal-line set to 61.

Distance-sensitive scoring changes the tie relation: P0 chooses fastest forced wins and P1 chooses longest resistance. Issue #41 then gives the stricter 28-line terminal set, all ending on ply 41.

Therefore use the hierarchy

```text
69 geometric axioms
  -> 61 W/D/L-optimal terminal lines (coarse tie relation)
  -> 28 distance-optimal terminal lines (refined tie relation)
```

The 61 is a useful control, not the final best-move object.

## Re-derived 28-line selector

Using only the issue's solved-oracle premises for this validation control:

- first five plies are center-column moves;
- P0 consequently owns center rows 1,3,5 one-based;
- P1 owns center rows 2,4 one-based;
- distance-optimal terminal ply is 41;
- the last landing must therefore be in row 5 or 6 one-based.

Filtering the 69 rule-derived lines by those necessary conditions reproduces exactly the issue's 28 line IDs and orientation count:

```text
12 vertical + 8 horizontal + 8 diagonal = 28.
```

## Comparison with the common GF(2) Y

Let `E_opt` be the 28-dimensional coordinate subspace of `F_2^69` generated by those 28 line basis vectors. The executable audit finds:

```text
dim E_opt                       = 28
rank(B | E_opt)                = 26
dim(E_opt intersect ker B)     = 2
```

Both line dependencies also have zero vertical-line parity, hence both lie inside the qualified common line core `Y_line`. Their supports are

```text
{34,35,37,43,53,58}
{13,14,27,28,61,62}
```

and horizontal reflection exchanges the two dependencies.

Thus the external 28-line coordinate set is not a basis of `Y_line`: its intersection with `Y_line` has dimension 2, not 28.

On the cell side, let `S_opt = B(E_opt)`. Then

```text
dim S_opt                         = 26
rank(axis parity | S_opt)         = 6
dim(S_opt intersect Y_cell)       = 20.
```

So the optimal-line coordinate space has the exact incidence filtration

```text
28 = 2 + 20 + 6
     |   |    |
     |   |    +-- axis-boundary image
     |   +------- cell-core image inside Y_cell
     +----------- line dependencies inside Y_line
```

This is a real structural relation, but it is not the identity `28 optimal lines = common Y`.

## The missing seventh cell-boundary coordinate

The qualified cell quotient has seven natural axis-interval coordinates: four length-4 column intervals and three length-4 row intervals.

The optimal 28-line image spans six of them. The unique missing coordinate is the first row-interval coordinate, corresponding to the vertical interval spanning rows 1..4 one-based.

That absence has a direct terminal explanation: a winning line confined to rows 1..4 cannot contain the move-41 landing, which must be in row 5 or 6.

Equivalently,

```text
dim(S_opt + Y_cell) = 34
```

inside the 35-dimensional `im(B)`, so the distance-optimal terminal geometry misses exactly one image direction, and that direction is identified geometrically rather than by arbitrary elimination.

## Interpretation

Issue #41 materially strengthens the case that the repeated 28 is structural, while also falsifying the simplest identification.

The current evidence says:

```text
common structural Y:            dimension 28
optimal terminal line set:      cardinality 28
optimal line coordinate span:   dimension 28
its incidence image:            dimension 26
line-side overlap with Y_line:  dimension 2
cell-side overlap with Y_cell:  dimension 20
boundary contribution:          dimension 6
```

So the matching cardinality is not explained by the 28 terminal lines simply serving as a basis for the middle object. Any deeper identification has to explain the `2 + 20 + 6` filtration and the missing bottom vertical boundary coordinate.

A particularly useful next comparison, once the exact 61-line set is preserved in machine-readable form, is to compute the same incidence fingerprint for `69 -> 61 -> 28`. That will show which dimensions disappear when the tie relation is refined from W/D/L-only to distance-sensitive optimality.

## Proof boundary

- Issue #41 is external solved-oracle validation evidence.
- None of its solved W/D/L or distance premises are used to prove the target-free common-Y theorem.
- The general 69 winning lines remain the domain authority for arbitrary positions and imperfect play.
