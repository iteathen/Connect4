## Implemented topology

```text
shared RBA TT
  ├─ exact q identity and bounds
  ├─ dependency edges
  ├─ ready q queue
  └─ event queue

manager thread
  └─ attach/reconcile events and expose surplus dependencies

evaluator workers
  ├─ claim ready q
  ├─ evaluate CPC/RBA outside TT transaction
  ├─ publish exact/scalar/child evidence
  ├─ retain first runnable child
  └─ surplus unresolved children become manager-exposed ready work
```

There is no independently authoritative branch queue. The ready queue is embedded
in q rows and protected by the same generation/ref/execution lifecycle as the TT.

## Deliberate limits

The shared ready queue is currently FIFO across q arrivals. Local action order
and CPC intervals affect retained-child/publication order, but a global
highest-value priority queue is not yet implemented.

The manager uses one TT transaction for topology operations and may become a
contention point. No lock-sharding or second scheduling authority is introduced
without evidence.

The earlier Fhourstones run `35927770000` was generated by the superseded
private one-worker alpha-beta wrapper. It is historical control evidence only;
the Branch Manager topology requires a new benchmark before any Fhourstones
score is attributed to it.
